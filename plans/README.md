### 001 — REJECTED (the audit finding was invalid)

The audit claimed the action bars showed a stale selected-count after a column
filter excluded a selected row, because they read
`table.getFilteredSelectedRowModel()` without subscribing to filter state. That
premise assumed v8 semantics. **Verified against the installed engine**
(`@tanstack/table-core@9.0.0-beta.9`,
`features/row-selection/rowSelectionFeature.utils.js` →
`table_getFilteredSelectedRowModel`): in v9-beta.9 that method builds from
`table.getCoreRowModel()`, **not** the filtered model — it is identical to
`getSelectedRowModel`. A focused diagnostic confirmed it empirically: with a
selected row filtered out (filtered model = 1 row),
`getFilteredSelectedRowModel().rows.length` stayed at 1 even though the bar
re-rendered. So the selected count never depends on filters, the described bug
cannot occur, and the proposed `columnFilters`/`globalFilter` subscriptions
would only add redundant re-renders. The plan was implemented, its own
regression test failed to reproduce the bug, the root cause was traced to the
engine, and the change was reverted. (Contrast `DataTablePagination`, which
legitimately subscribes to filters because it renders
`getFilteredRowModel().rows.length` — a genuinely filter-derived value.)

### 004 — as-built note (broader than the original plan below)

The plan text below adds the restriction only to the
`apps/*/components/**` + `apps/*/features/**` + `packages/ui/**` block. Probe
testing during review found that block does **not** cover `apps/*/app/**` —
where this repo's table column files live (`apps/*/app/**/columns.tsx`) — so the
boundary would have stayed unenforced at the most important location. The
as-built fix defines a shared `tableEngineImportRestriction` and spreads it into
the `apps/**` block, the components/features/ui block, and the
`apps/*/app/api/**` block (flat-config rules do not merge across blocks, so each
must carry it), keeping the `tanstack.ts` / `types.ts` exemption. Verified by
probes firing in `apps/*/app/`, `apps/*/app/api/`, `apps/*/features/`, and
`packages/ui/`.
