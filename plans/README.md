## Findings considered and rejected

- `vendor/payload-upstream/**` + `.next-docs/**` Radix matches: vendored /
  generated third-party content, not active frontend — documented exception,
  no plan.
- TanStack Table `data-state={row.getIsSelected() && "selected"}` and
  Sidebar's repo-set `data-state` (`packages/ui/components/shadcn/sidebar.tsx:206`):
  not Radix attributes — explicitly kept; conversion rules carry keep-rules.
- `.eslint-donor.json` / `.eslint-missionary.json` `asChild` matches:
  generated source-snapshot fixtures, excluded from gates via `--glob '!*.json'`.
- Admin's duplicated mission-control app-shell implementations (two
  generations both needing migration): consolidation is real tech debt but
  out of scope for this migration branch — candidate for the architecture
  review pass (loop iteration 3).
