## Approach

Keep the reviewed upstream source revision and MIT notice in the source
audit. Adapt the canonical skill where Core's invocation, authorization,
and provider coverage differ. Generate all runtime mirrors with the
existing skill synchronization command.

Use the harness's available delegation tools. T3 Code resolves providers
through its capability tool. A harness without all default providers may
provide one labeled native-only round when the request leaves the member
list open. Explicit provider requirements remain authoritative. A maximum
of three rounds permits two follow-ups. Each round stops waiting after ten
minutes or when the request's remaining time budget expires. The coordinator
reports missing coverage and requests cancellation where supported.

## Verification

Check opt-in discovery, a one-member request, review-only operation,
authorized fixes with persistent dissent, and unavailable provider behavior
against the canonical instructions. Verify the pinned source and license,
audit coverage, and the generated mirrors.
