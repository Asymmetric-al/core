# Add reviewed security auditing and refresh installed skills

## Why

Core needs the reviewed Cloudflare audit workflow available consistently across
coding clients. The installed catalog also contains stale upstream content,
unattributed ecosystem sources and outdated maintenance instructions.

## What Changes

- Vendor the complete reviewed Cloudflare package with its license and Core overlay.
- Add an immutable, transactional focused refresh and complete-tree publication.
- Refresh only installed, verified sources while retaining Core policy and aliases.
- Account for all installed skills, retained snapshots and unresolved sources.
- Preserve the excluded PDF payload byte-for-byte across all three runtime trees.
- Correct project-local installation, source ownership and verification guidance.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `agent-instruction-system`: reviewed security-audit operating boundaries,
  immutable package refresh and complete installed-skill audit accounting.

## Impact

Only coding-agent skill sources, provenance/lock metadata, maintenance tooling,
routing, generated mirrors and focused tests change. Product code, dependency
versions, credentials and global configuration remain outside this work.
