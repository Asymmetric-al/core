## Compatibility repairs and tests

Both Core repairs remain necessary. The stock release still loses ownership
across a consumer's local barrel and rejects exact typography-plugin contract
classes that the actual Tailwind compiler can generate. The new
`tooling/eslint-config/patches/@shadcn%2Flint@0.2.0.patch` modifies only
`dist/index.js` in two hunks; the installed result matches the independently
prepared candidate byte for byte. It preserves upstream node_modules checks,
the new single-file-component fallback, invalid-class failures and broken-theme
warnings.

The new commented-barrel regression demonstrates a real 0.1.5 failure: a legal
`CardTitle` typography class is reported as a consumer override when comments
pollute its resolved component name. Patched 0.2.0 preserves canonical Button
identity, rejects both Button padding overrides, permits the title's typography,
and leaves an unrelated ordinary component unaffected.
