## ESLint 10 compatibility

ESLint 10.11.0 is the current major release. The compatible 9.39.5 maintenance
release is still past its support window (2026-08-06). The installed/latest
React plugin 7.37.5 supports peers through ESLint 9 and calls the removed
`context.getFilename()` API, causing the documented `react/display-name` crash.
The latest JSX-a11y 6.10.2 and import 2.32.0 plugins also exclude ESLint 10.
Next's latest config 16.3.5 retains those dependencies, so upgrading that config
alone does not provide a supported migration. React-hooks 7.1.1 supports ESLint
10, while the installed 7.0.1 does not. Installed TS-ESLint 8.58.2, import-x
4.16.2, and unused-imports 4.4.1 support ESLint 10. Do not force incompatible
peers or disable framework checks to claim a supported migration.
