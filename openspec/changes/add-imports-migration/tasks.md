These are OpenSpec plan items for the `imports-migration` capability. They are not tracker tickets and authorize no implementation; implementation tickets require a separate `/to-ticket` authorization. Every behavioral task uses red-green-refactor at the nearest confirmed test seam (design § Test Seams). Do not mark a task complete without evidence.
