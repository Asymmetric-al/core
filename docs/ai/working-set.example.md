# Working Set Example

Copy this file to `docs/ai/working-set.local.md` for local agent scratch context.
`docs/ai/working-set.local.md` is gitignored and must not be committed.

`docs/ai/working-set.md` is a different file: a tracked historical record of
dated entries. Do not copy this template over it or add new scratch to it.

## YYYY-MM-DD (short task name)

- Date: YYYY-MM-DD
- Repo: Asymmetric-al/core
- Goal: One sentence describing the current task.
- Primary area:
  - `path/to/file-or-module`
- Constraints:
  - Runtime, tooling, security, or behavior constraints that should shape Nia queries.
- Evidence sources used:
  - Rulebooks, skills, docs, commands, or Nia sources already checked.
