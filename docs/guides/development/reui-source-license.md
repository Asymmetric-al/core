# ReUI Pro source distribution in Core

On 2026-10-07, Core's repository owner explicitly confirmed that a separate
agreement permits publishing ReUI Pro block source and modified derivatives in
this public AGPL repository, including access by its contributors. This records
the owner's confirmation; the agreement document was not supplied or
independently reviewed in this session.

Use this confirmed permission for Pro blocks available to the provisioned
account. Keep source provenance, copyright notices, and the distinction between
commercial Pro source and public MIT components/examples. Do not describe Pro
source as MIT or infer additional account entitlements. Motion Icons still
require Ultimate and Core continues to use Lucide.

The account credential authenticates registry and MCP access; it is not the
evidence of distribution permission. That permission comes from the owner's
separate agreement confirmation above. Never commit the credential or private
agreement material. The normal ReUI license remains the reference for usage
outside the confirmed agreement's scope:
https://reui.io/legal/license.

This permission does not authorize purchases, repository visibility changes,
deployments, business capability changes, or primitive/theme migrations.
