# ADR-0186: Complete bounded Site Brand Versions

**Status:** Accepted (founder ruling, Phase 24 D59 — 2026-08-30)

Each Site owns complete immutable Site Brand Versions for its public website
and public-giving presentation. Phase 24 owns the quiet self-service management
experience; the applicable public-Site release authority pins an exact
qualified version into public output. D59 creates no second serving head,
renderer, theme store, or publication workflow.

Ordinary staff branding is deliberately expressive but bounded: approved
identity assets, dedicated semantic brand roles, compatible typography choices,
and finite purpose-named presentation options from the qualified presentation
contract. It cannot contain staff-supplied runtime code, remote modules,
arbitrary CSS, executable templates, custom breakpoints, tracking, or overrides
of Core's product, security, accessibility, legal, or payment semantics.
Navigation/content, media custody, renderer code, Site/domain/lifecycle,
Legal Entity, money, authentication, the Tenant Donor Account Brand, and Phase
17 message Brand Kits retain their own authority.

Starting from an exact compatible projection of the Tenant Donor Account Brand
or a code-owned compatible preset creates a complete independent draft with
provenance; it never creates live inheritance or makes the account brand a Site
authority. Drafts do not affect public output. Production-faithful preview and
whole-candidate validation precede the existing expected-head release path;
failure preserves current public output and restore creates a newly proved
successor through the applicable release authority.

A separately governed, source-controlled certified Presentation Package lane
may exist only under its own accepted contract and qualification. It is not a
Web Studio code upload and D59 grants it no exception from Core's governing UI,
security, accessibility, or release rules. This preserves genuine ministry
brand distinction without creating a Tenant plugin platform or a parallel
public authority.
