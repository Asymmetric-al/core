# Capability-certified Accounting Delivery Packages

**Status:** Accepted (founder ruling, Phase 20 grill session — D16)

The staff-mediated QuickBooks Online and Xero lane produces one immutable
**Accounting Delivery Package** from the exact frozen Provider Delivery Plan.
The package is pinned to one Tenant, Legal Entity, accounting destination,
delivery lane, currency, accounting date, governing D4-D8 and D11 versions,
compiler, and provider contract. Broad tenant control remains prospective
through those existing authorities; Asym owns the provider-required schema,
encoding, limits, partitioning, control totals, privacy contract, exact bytes,
and recovery semantics.

A package is **Ready to import** only while the exact destination Capability
Certificate and a narrow **Import Surface Conformance Record** are current. The
conformance record proves one exact provider, region, subscription capability,
importer, template, serializer, limit set, and recovery behavior. It is not a
second tenant configuration model and does not certify provider permission,
successful import, finalization, effect verification, or reconciliation.
Unsupported Posting Profiles fail closed instead of receiving a generic CSV,
manual-journal substitution, fabricated bank statement, or other lossy
fallback.

Staff use one three-step surface: review the exact destination and accounting
effect, download one file or ordered parts with an optional bundle, and record
what happened. Download, staff testimony, provider staging or draft,
finalization, exact readback, mismatch, drift, and reconciliation remain
separate append-only evidence. Re-download returns the original bytes;
re-import is never retry. Partial or uncertain outcomes use the existing D13
exception contract, and a recovery package may contain only exact work proved
not to have been imported.

## Phase 21 D26 precision amendment (2026-08-02)

A Phase 21 Records Export Package is never an Accounting Delivery Package,
Provider Delivery Plan, QBO/Xero import surface, Accounting Release, provider
operation, readback, drift result, or reconciliation evidence. It may contain a
currently authorized Phase 20 owner reference or exact evidence copy, but
downloading, storing, transferring, or importing that records package creates
no accounting work and cannot post, reverse, reconcile, clear an exception, or
serve as a QBO/Xero company-file backup.
