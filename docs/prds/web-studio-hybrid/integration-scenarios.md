# Cross-product Web integration scenarios

These additional cases are cumulative with all 96 paired HW scenarios. Their source text is the [program delivery contract](../program-roadmap/delivery-contract.md#integration-proof-that-must-not-be-lost); this mapping identifies exact Web task scopes without creating a new business owner. None is executed runtime evidence.

HA-INT-04 consumes the real Phase 12 NHI denial and D13 organization-appointment contracts. It must not import or require completed Phase 34 to prove native Web scheduling; when an optional Studio consumer is later qualified, re-prove its same source denial through that integration. This is source-policy proof, not a substitute allow/deny mock.
