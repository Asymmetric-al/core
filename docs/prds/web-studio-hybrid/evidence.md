## Material verification results

1. Current Core remains at the inspected develop SHA. Phase 23 PR #1340 is open/unmerged.
2. Current admin remains partly Payload-form-owned; replacing it requires lifecycle parity, not cosmetic replacement.
3. D7 needs an explicit amendment before bounded containers become authorable. D12 and D13 already define draft/schedule behavior and must not be replaced.
4. Puck 0.23.0 is the starting evaluation candidate, not an automatically approved dependency.
5. The Payload stable-release API returns 3.89.0; the repo uses an internal v4 pin. D34 remains an explicit blocking cohort gate, with no silent v3 downgrade.
6. npm dist-tag web retrieval failed in this session. The GitHub release API was checked instead; no universal claim about npm channels or all prereleases is made.
7. The browser IDE/hosted AI project and accidental help-desk review are not dependencies.
8. External benchmark capabilities inform design, not assertions about how all developers prefer to work. No empirical ministry usability study was performed.
