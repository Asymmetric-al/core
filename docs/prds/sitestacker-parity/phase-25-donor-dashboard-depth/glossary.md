# Phase 25 glossary

These are navigation definitions for the ratified Phase 25 proposal. The referenced contracts contain the exact scope and invariants. The root [CONTEXT.md](../../../../CONTEXT.md#phase-25-donor-self-service-language) uses these same canonical labels. The [historical terminology notebook](research/phase25-grooming-terms.md) preserves the fuller decision chronology; its stage-specific wording does not reopen accepted execution.

| Term                                 | Meaning and controlling contract                                                                                                                                                                                                                                               |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Personal giving                      | The human's currently admitted personal financial context; it is not a required donor row for every account holder. [IC02](contracts/identity.md#ic02--current-context-and-representation).                                                                                    |
| Giving you help manage               | Separately admitted represented financial work. Switching views does not change personal reading, contact or communication subjects. [IC02](contracts/identity.md#ic02--current-context-and-representation).                                                                   |
| Ministry Update                      | An Asym published post with source-owned audience and access. It is distinct from a missionary's separately managed newsletter. [Experience contract](contracts/experience.md).                                                                                                |
| Newsletter request                   | A recorded request to receive a named missionary's newsletter. Forwarding, receipt, enrollment, newsletter sending and delivery are separate facts. [Experience contract](contracts/experience.md).                                                                            |
| Sign-in email                        | The mutable address identifying an account in the email-first sign-in journey; it is neither an authenticator by itself nor immutable account identity. [IC06](contracts/identity.md#ic06--selected-related-email-changes-and-stable-claim-proof).                             |
| Contact email with this organization | The person's source-owned contact address within this Tenant's donor/Party context, separate from sign-in credentials and each message's consent, security and delivery rules. [IC06](contracts/identity.md#ic06--selected-related-email-changes-and-stable-claim-proof).      |
| Current Home need                    | An authorized presentation of an exact source-owned donor step or required continuing state; it is not an unread notification or a separate completion record. [EX07](contracts/experience.md#ex07--source-owned-needs-attention).                                             |
| New-gift preference                  | An optional suggestion for eligible future checkout; it neither changes existing recurring agreements nor establishes a provider Customer default. [Recurring contract](contracts/recurring.md).                                                                               |
| Recurring giving                     | An accepted source-owned arrangement with its own schedule, authorization, payment and recovery state. It is distinct from a fixed-total pledge. [Recurring contract](contracts/recurring.md).                                                                                 |
| Fixed-total pledge                   | A Commitment Party's explicit cumulative promise with source-owned fulfillment; it is not itself money, donor debt or automatic payment authority. The [existing root definition](../../../../CONTEXT.md) continues to govern. [Recurring contract](contracts/recurring.md).   |
| Gift amount                          | The original gift's source-defined monetary fact. Corrections and the separately defined Current giving amount do not rewrite it. [Financial contract](contracts/financial.md).                                                                                                |
| Current giving amount                | The exact source-projected current monetary measure used by the ratified annual context and its export. It is not a deductible total, FX conversion or browser sum. [Financial contract](contracts/financial.md).                                                              |
| Receipts & statements                | The dedicated entrance to currently admitted source-owned documents. It does not create a new issuer, archive or financial authority. [Financial contract](contracts/financial.md).                                                                                            |
| Received DAF grant                   | A received sponsor grant associated through admitted recognition evidence. The advisor's awareness view is not another charitable deduction or ordinary personal tax receipt. [Financial contract](contracts/financial.md).                                                    |
| IRA gift with QCD intent             | A source-recorded IRA-origin transfer by the resolved owner or applicable inherited-IRA beneficiary, with a separate custodian and evidenced intent. Source/document admission and final personal tax treatment remain distinct. [Financial contract](contracts/financial.md). |
| Known empty                          | Current authoritative evidence establishes no admitted records. It is distinct from unknown, unavailable, denied or stale data. [Shared decisions](contracts/shared.md).                                                                                                       |
| Zero-artifact rule                   | Known irrelevance of an optional rare-record surface leaves no ordinary navigation, count, placeholder or promotional UI. It does not suppress truthful explicit-route failure. [Experience contract](contracts/experience.md).                                                |
| Founder-ratified                     | A product decision was accepted. It is not synonymous with merged, implemented, activated or production-qualified. [Evidence](evidence.md).                                                                                                                                    |
| G01                                  | The unresolved supported native Supabase linking guarantee and required endpoint proof before affected social activation. It is not evidence of a live exploit or permission to invent an alternative identity system. [Shared gates](contracts/shared.md).                    |
