# Phase 27 — Operating controls

All adopted controls remain binding. Thresholds are planning triggers, not measured service promises. Before activation, assign each accountable role to an actual person/on-call team and exercise the response. Preventive authorization, financial-integrity and source invariants are release gates, never risks deferred to monitoring. Where a control refers to an admitted budget, Q12 requires its numeric value, units, workload and evidence before activation. Multiple decision rows observing the same incident may share one underlying signal and incident; preserving trace does not require duplicate alerts or tasks.
