## Delivery boundaries

SMS-CHANNEL supplies qualified channel capabilities; SMS-CONVERSATIONS additionally requires the exact Phase 26 adapter; SMS-OUTREACH additionally requires Phase 32 campaign and Phase 5/13 giving contracts. W11/W12 retain cross-lane migration, recovery and full-profile proof. No Phase 31, Phase 32 email, Workflow CORE, enterprise identity or native source product acquires a backward dependency on Phase 43. SMS availability never enables SMS authentication or ordinary clinical/crisis disclosure.

Carry all 32 SMS cases and the applicable shared `EXT-INT-01`–`EXT-INT-12` and `IG-AT-*` cases into implementation evidence. Passing the local map verifier is not any of those tests passing. Publish implementation tickets only after overlap checks and affected source decisions; keep local IDs and link exact existing owner tickets rather than cloning them.
