`before-index.json`, `after-index.json`, their checksums, and the images under `before/` and `after/` are durable evidence. Checkout paths, raw archives, temporary configs, and logs under `/tmp/core-ui-audit` are local-only diagnostics. They are not links to hosted artifacts or proof of provider availability.

The baseline source is `f49fc2e03`. It was preserved in a separate checkout while implementation proceeded on the UI branch. Application captures used the repository's existing `dev:playwright` script, one application at a time after a memory-limited cold-compilation failure. Ports were donor 3005, admin 3030, and missionary 4000. The browser used installed Playwright Test 1.59.1 and system Chromium `/usr/bin/chromium`.

The runtime used the existing CI datasource (`https://example.supabase.co`, placeholder anon key), `ASYM_USE_CI_ENV_DEFAULTS=1`, `SKIP_ENV_VALIDATION=1`, `E2E_AUTH_BYPASS=true`, and the owning `ASYM_E2E_AUTH_SURFACE`. Service-role, payment, email-provider, and demo-password values were explicitly empty. Payload pointed at the unavailable local Postgres port 54322. The browser posted the existing local `/api/auth/demo-account` helper with the role for the application; it did not use hosted sign-in or save cookies. Do not use production provider values to reproduce these captures.

Application screenshots use 1440 × 1000 and 390 × 844 viewports, supported application theme modes, and reduced motion. Capture waits for visible route headings, available skeleton resolution, and settled transitions. Most overlay captures advance finite CSS animations; final Giving and report-chart captures allow animations and wait for actual opacity1 and stable SVG series/clip geometry. The Giving fixture must include the application MotionProvider. Chart captures expand the viewport to the page height, wait for the real resize/animation, and capture that viewport without overriding component animation props. Productive forms, tables, maps, or CMS editors that remain unavailable must retain that disposition.

The eight focused component suites run without application servers or provider access. Each suite bundles its actual repository fixture and checks rendering, interactions, and accessibility in a blocked-network browser. To reproduce the same selected gate from the repository root with an installed system browser:

```sh
UI_AUDIT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium node node_modules/@playwright/test/cli.js test --config docs/qa/core-ui/component-check.config.mts
```

Omit that environment variable to use the normal installed Playwright browser. This selected gate complements the normal repository Playwright workflows; it does not replace their auth, table, form, navigation, CMS, or production checks.
