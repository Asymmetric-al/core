## Evidence limits

[Runtime baseline](./runtime-baseline.md) and the [before index](./before-index.json)
are authoritative for actual captured routes, fixtures, viewport/state metadata,
failures and excluded screenshots. A screenshot of a configuration error or
startup chrome does not prove a productive gallery, editor, ticket list or
payment flow. An isolated fixture mounts actual components at existing inert
public seams; it establishes component behavior/layout, never application or
provider availability.

Owner-focused unit/type/format results are recorded in the detailed inventories.
They overlap and are not summed into a repository total. Final aggregate gates,
affected builds and preflight are owned by the
[final verification record](./verification.md), which states exact results and
remaining limits. The [integrity record](./sources/evidence-integrity.json)
checks source identities, joins, image paths/hashes and local references without
turning them into runtime or provider passes.

All 638 indexed images retain their actual Next 16.3.8 pre-integration scope:
297 before, 341 after and 295 pairs. The later
[upstream integration](./sources/upstream-integration-review.md) preserves the
original baseline, refreshes only changed current identities and records
Next 16.4 as inherited develop configuration. These earlier pixels are not
post-integration runtime validation. The
[remaining token report](./sources/token-drift-retention-review.json) joins all
275 reportable neutral-palette hits to 15 dormant source modules and explicit
retention evidence; it is not a token-free claim.

[Token contrast](./token-contrast.json) and the
[camera-chip estimate](./missionary-camera-contrast.json) are mathematical
estimates with explicit compositing assumptions. Actual computed CSS, image
context and supported light/dark states require browser evidence.

[Public MIT source research](./sources/reui-research.json) identifies inspected
examples and dependencies; [its notice](./sources/LICENSE-ReUI-MIT.md) applies
to those public examples. [Commercial Pro research](./sources/reui-pro-research.json)
and [derivative mappings](./sources/reui-pro-settings.json) separately identify
paid source and the [owner-confirmed permission](../../guides/development/reui-source-license.md).
The Pro derivatives are commercial source and are not labelled MIT.
