# Contribution-detail decision records

The `ADR-CD-*` namespace and filenames remain stable. Current Decision and
Consequences sections incorporate the ratified owner contracts as of
2026-09-16 (AL-1861). Each changed record states its amendment date and links to
the immutable original dated decision and rationale; no later ruling is
backdated into the original founder session.

Use the [current owner map](../../README.md) and
[document authority guide](../../../../../ai/document-authority.md). The active
records use the Phase 13 ledger and campaign model, Phase 12 optional-approval
policy, Phase 16 recurring authority and Phase 7/17/18/19 document/message
owners. Valid shared UI, concurrency, audit, navigation and action-boundary
decisions remain in their actual bodies. No record authorizes reviving Twenty.
