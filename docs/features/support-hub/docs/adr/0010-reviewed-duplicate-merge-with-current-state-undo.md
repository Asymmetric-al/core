## Why this shape

Keeping independent work is smaller; closing a duplicate with a reference tidies the queue but permits later independent reopening. Reviewed continuation addresses repeated duplicate coordination. Destructive absorption, source deletion and snapshot rollback cannot deliver dependable Undo after later messages or owner actions. Retaining source identities while composing one staff history gives the selected work experience and a real separation capability without a second CRM or general workflow/graph platform.

Active merge relationships form a narrow forest: one active parent per source, no cycles, merge current distinct roots only. Undo ends its exact active edge and detaches its current subtree, including after other merges. For B→A then A→C, Undo B→A separates B while A/C remain; Undo A→C separates A and current descendants. Later independent additions to C stay there. Ended operations cannot undo a later re-merge. Current root lookup is derived navigation/control context, never a permanent cached redirect or historical write authority.
