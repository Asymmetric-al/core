## Decision

Support staff can deliberately start temporary coverage for one actual person/tenant and an explicit reviewed inbox set. Start now, optionally choose a future end instant, otherwise Until I end coverage. Current Open work, including deferred Open, transfers through the qualified assignment boundary to its existing responsible inbox as Unassigned, preserving team/work/reminders/history. Quiet waits and resolved history remain assigned until valid D3 work makes review necessary. Later human input, due reminders, owner/recovery evidence, authorized Set Open and already-Open fresh work are covered; no extra requester email or status-string change is required.

Shared release is custody, not a claim that a person accepted or answered the request. Missing independent qualified cover, paused automation and other failures remain visible incomplete handoffs in safe current ownership. Eligible scope can proceed without claiming the entire person/portfolio is covered.

## Why this tradeoff

A reviewed manual handoff is simpler but requires continued human monitoring for late reopens and due work. Transferring all unfinished work upfront clearly hands over the whole portfolio but moves quiet waits unnecessarily. B covers current and future actionable work with less churn. It needs one explicit bounded coverage lifecycle, not a workforce calendar, backup owner or generic rule platform.

## Invariants and reconciliations

Keep the stored tenant-wide Receive preference unchanged. Coverage adds an effective new-automatic-assignment restriction only in selected inboxes; On cannot bypass it, while other inboxes retain their current eligibility. Ending/removing scope removes that restriction and uses the current preference; it writes no stale restoration. No automatic handback follows return.

Coverage uses a distinct later-assignment cause, product-owned current scope/control and the shared dispatch/claim mechanisms. It cannot mint another D6 initial source or invoke rotation merely because a prior owner becomes null. The canonical conditional transaction owns actual assignment/team, actor/system cause, history and durable outcomes. D3 work and required evaluation intent commit together; handler failure does not erase admitted work.

An explicit Keep with the covered person is episode/assignment-control bound and visible in the normal assignment flow. Same-owner Keep is control evidence, not a fabricated reassignment metric/notice. Ordinary status/Send/note/unsnooze creates no Keep. New owner, scope exit/removal or episode end invalidates it; extending only end preserves valid choices. Move-retain into active coverage resolves the same deliberate handling choice; old scope is fenced and move is not intake.

Use fresh authoritative effect-admission time after current guarded controls, not sender or stale transaction-start time. End is exclusive; merely queued old evaluation gets no retrospective authority. A valid admitted effect may complete later with its history intact. End stops future effects without undoing committed transfers. Expired cleanup cannot block a new guarded Start. Scope changes are explicit versioned commands; new inboxes/grants never silently expand scope.

D6 Pause also holds autonomous coverage releases. Resume catches up current eligible Open only while the episode/scope/control still applies. Partial/unknown outcomes remain durable and visible. Current canonical IDs, not incomplete display hydration, decide assignment: missing display data is Unknown, not Unassigned.

Coverage grants no CRM/giving/member-care/representative authority, creates no Party, changes no owner outcome and sends no donor notice. Private drafts do not transfer. Already admitted prepared mail keeps author/audience/material/effect; normal D1/D2/D4 send/collision/recovery rules remain. Fixed personal Support operation versus configurable automation governance requires explicit later owner/OpenSpec qualification; no current capability is presumed implemented.
