New human Support email replies include the new answer and governed signature/footer without automatically appending older body text. Staff can deliberately insert a source-qualified quotation directly in the existing editor. Automatic selected-message quotation was the strongest alternative, but deliberate inclusion better preserves focused answers and controlled redistribution while keeping useful context one action away.
