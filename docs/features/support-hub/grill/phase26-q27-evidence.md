## Root recommendation and pressure test

A is the single recommendation: selected current public guidance, deliberate preview and link insertion. It adds a useful source-finding journey beside existing D18 wording while keeping publication ownership with Web Studio and email ownership with P17/P6. B remains strongest for a small set of well-maintained saved links. C remains strongest when staff procedure consultation is an intended requirement worth a qualified internal source/lifecycle; no evidence makes that universal.

The selected answer must resolve current source/public reachability, curators versus publishers, site/language disambiguation, stable references, URL changes, withdrawal after insertion, safe source checks at the actual send boundary, personal draft preservation, current access, bounded complete lookup, low-bandwidth/mobile/AT behavior and content maintenance. It must not assume arbitrary runtime URL fetching, full article cloning, automatic query extraction from private conversations, AI answer generation or another knowledge editor. The exact solutions belong to the answer's full adversarial review, not to an unselected schema.

No new generic CRM context is needed: D26 already provides the shared detail. Viewing guidance is not a CRM fact, record link, actual communication, business-action permission or proof a case was solved. Reading an internal item under C would not alone authorize external sharing, export, AI egress or insertion into a public draft.
