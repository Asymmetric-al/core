The selected synthesis chooses one source-item literal contract; no redundant Match-mode selector or arbitrary Boolean language. All entered fragments must match one item, so scattered-message recall is intentionally narrower; Person or email plus content query expresses an explicit useful cross-field condition. Unicode matching/highlights use one versioned contract. The existing 200ms debounce is an initial interaction value; 256 scalars/1,024 bytes/16 atoms are explicit product input bounds, not vendor limits. Real normalized expansion/source/query/freshness/recovery budgets remain owner-qualified activation evidence.

Final independent corrections are incorporated: Search in is dormant with blank text rather than becoming an existence filter; empty Find clears matches; Clear filters explicitly resets Search in while keeping current inbox and mandatory context; exact-reference priority requires a single complete reference atom. Supported legacy query meanings can remain versioned inside one qualified owner—no parallel engine or unsafe forced reinterpretation. Immediate loss of serving authority is separate from bounded physical cleanup/preservation/restore; independently authored query configuration retains D20 purpose while source-derived fragments keep restrictions.

Future AI/broader intent is recorded without current embeddings, content extraction, model/egress calls, generic plugin infrastructure or disabled product chrome. The current source contract is the deliberate reusable seam.
