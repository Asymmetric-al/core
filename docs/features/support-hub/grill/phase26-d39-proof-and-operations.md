## Residual operating controls

Reuse existing Support engineering/security/design responsibilities. Actual accountable people/teams and P27 workload/latency budgets must be assigned before activation. These numerical alert policies are **proposed operating judgments**, not vendor best-practice constants or performance promises. Safety/correctness defects below block release and trigger containment after release; they are never excused by low event counts.
