## Residual operating controls

Accountability refers to release-assigned roles; deployment must name an actual on-call/team for each. These are proposed initial response thresholds, not measured baselines or vendor limits. Correctness is a release gate as well as an incident trigger. Use the existing observability/repair system rather than a new quote dashboard.

| ID  | Signal and exact threshold                                                                                                                                                                                                         | Accountable owner                                       | Response                                                                                                                                                                                                                                                  |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| O01 | Any confirmed cross-tenant/source disclosure, unexpected active quote token/resource, or prepared-versus-reviewed material mismatch: **one event**.                                                                                | Support engineering on-call with security/privacy owner | Immediately stop affected new quotation/preparation, preserve body-free evidence, apply source/provider owner containment and correct/verify before re-enable; do not replay possibly submitted mail.                                                     |
| O02 | Eligible quote extraction technical-failure rate **over 2%** in a rolling **15 minutes** with **at least 100 eligible attempts**. User cancel, explicit policy denial and over-limit validation are excluded and separately typed. | Support engineering on-call                             | Diagnose source/compiler/storage/timeout root cause; scope-disable quote insertion if persistent, preserve plain replies and fix/retest. Low-volume tenants are not claimed covered by this aggregate alert; direct failures stay visible and reportable. |
| O03 | Extraction p95 exceeds the release-qualified shared budget in **two consecutive 15-minute windows**, each with **at least 100 completed eligible operations**.                                                                     | Support performance owner                               | Inspect payload/concurrency/region evidence; bound work or repair regression. Do not relax authorization or silently truncate. The actual budget must be published by P09/P29 before activation.                                                          |
| O04 | Any confirmed stale result resurrecting a removed quote, lost authored text, duplicate durable insertion from one operation, or duplicate send: **one event**.                                                                     | Support draft owner; P6 delivery owner for actual sends | Contain affected action, reconcile the original operation, repair and add regression evidence before re-enable. Keep independently valid draft text.                                                                                                      |
| O05 | **Three independently reported occurrences of the same quoting task obstacle within 30 days**, or **one reproduced accessibility blocker**.                                                                                        | Support product/design owner with accessibility lead    | Reproduce in the actual journey, prioritize corrective design and retest affected tasks. Do not turn failure into a new setting/approval step by default. Record resolution in existing work tracking when authorized.                                    |
