**F04 — New actionable recovery after an otherwise valid Mark. Material concern found and corrected.** Initial R07/P07 concentrated on outstanding sends and events racing before Mark. A later genuinely actionable provider/owner result could be missed if an implementation treated Unwanted as unconditional current-work exclusion. Severity was **high**, likelihood **plausible asynchronous behavior**, grounded in D3-R08 and actual asynchronous communication ownership. This narrowed the source/work exclusion, not the selected B scope.

The permanent fix is now explicit in **R07/P07, C13, L09/trace22/proof9 and UX06/proof10**: end only the now-inapplicable current exclusion, expose the valid original/current work home for Open review, and preserve classification/communication history. Duplicate or already-reviewed evidence cannot repeatedly reopen work. The actual owner records any real obligation/purpose change; the transition creates no fabricated human message, native-content timestamp, reply fulfillment or D39 unread event. Existing future-hold policy is unaffected. **F04 is closed in the reviewed files.**

Two non-policy wording refinements were also verified: the result says **This action sends no email**, which does not deny or recall earlier/possibly submitted communication, and the future-hold review says it does not change email **already in Asym**, avoiding a promise based on the provider's received timestamp rather than canonical first acceptance. These make the accepted lifecycle understandable without changing its clock or adding another user decision.
