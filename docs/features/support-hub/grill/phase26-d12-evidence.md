## Actual-source observations

The probe extracts the exact current createInboundConversation helper and executes it with synthetic persistence/hydration dependencies. Source path, line range and full/extracted hashes are retained in the JSON. No environment, DB/Auth, provider or app bootstrap was invoked.

1. **Inbound assumptions:** the helper writes first/last/customer-message timestamps and inbound direction with message_count zero; it itself inserts no native message. That is a legitimate intermediate step for its inbound caller, but is unsuitable as staff-origin authority.
2. **Hydration failure and direct retry:** after a successful insert and failed hydration, one conversation row remains; retrying the same helper input creates a second generated row. The helper itself supplies no atomic durable creation receipt. This does not prove that every upstream durable caller duplicates or that a production incident occurred.

Mapper null-to-now behavior was separately source-inspected, not exercised as an additional experiment. No desired D12 state machine/model is presented as tested implementation. The fix is a qualified owner command and truthful staff-origin shape/readers, not indiscriminate rewriting of inbound behavior.

## Reconciled independent findings

The first synthesis settled new staff-origin work, a narrow original-scoped relation, exact source context, deliberate first-thread sending, no transitive CRM propagation, explicit referral and current-state correction. It names D3's non-success continuation ending and D2's new-thread composition extension rather than weakening D10/D11.

The second independent pass found nine concrete corrections, now incorporated in the full record:

1. **Exact contributing relations:** after merges, removing one displayed relationship must end the complete reviewed original contributor set under current topology, not one arbitrary edge.
2. **Administrative cancellation state:** use existing Resolved plus created_in_error and separate protected retirement control, not an undefined hidden fifth work status.
3. **Legacy write bypass:** fence generic conversation writes from forging staff-origin kind/provenance or bypassing compound receipt/citation admission.
4. **Immutable outbound source:** the new original owns the first-thread message; a changing current root only supplies handling/authorization and cannot silently retarget its saved intent.
5. **No stranded/cyclic continuation:** an ending must leave distinct current unfinished work in qualified custody; reciprocal endings cannot both succeed and historical endings are not future routing instructions.
6. **D8 restrictions follow actual work:** new-original creation cannot shed a required handling review; preserve/settle the source-scoped restriction without cloning unrelated holds.
7. **No unsafe expired-window retry:** provider-window expiry permits reconciliation only; keep ADR0032's strict typed outcomes, two follow-ups and deadline ceilings.
8. **Referral entry versus commit:** Refer to this conversation… opens the existing referral review; Refer update alone commits its reviewed effects.
9. **Content versus action macros:** new-thread insertion/preparation uses only D4's eligible content-only saved reply wording and presentation, never work-changing macro actions.

These are permanent adopted review amendments, not warnings delegated to implementers. The founder fully ratified B and this complete amendment package on 11 September 2026.
