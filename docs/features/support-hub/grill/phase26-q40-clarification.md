**Single best recommendation: A.** It solves the immediate handling problem with a clear recoverable action. B is stronger where repeated unwanted sender mail creates enough work to justify the additional inbound-policy capability and ongoing review; no such volume was established here. C is reasonable when the existing tools suffice and the extra disposition is not worth its scope. These are alternatives, not three settings to build.

Rechecked official documentation on15September2026: Front explicitly separates current-conversation marking from sender blocking and provides distinct recovery actions. Help Scout couples spam marking to future filtering and warns about using it for legitimate automated correspondence. This strengthens the case for explicit scope, without establishing a universal best practice or proving tenant demand. [Front](https://help.front.com/en/articles/2251), [Help Scout](https://docs.helpscout.com/article/307-manage-spam-and-unwanted-email).
