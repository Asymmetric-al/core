## Explicit effects

**Preview:** authorizes the actual reader request against its source; may create/reuse one private technical derivative and required access/generation evidence. It never copies the file into CRM, attaches it to a reply, creates a template asset, changes a signature, sends mail or marks the request done.

**Download original:** is a deliberate separately qualified retrieval of the immutable original. It is not a download of the generated preview under the original filename, nor a grant to bypass unscanned/blocked/removed content. It adds no generated official artifact or communication event. Already downloaded data cannot be recalled.

**Later deliberate reply attachment/reuse:** continues through D18/D23/D24 and D4's actual source/asset, audience, preparation and send guards. Existing P17/P6 contracts decide whether the exact bytes may be prepared and sent, including restrictions, consent/purpose, current recipients and irreversible submission. A ready preview is not proof that reuse/send is allowed, and the viewer offers no automatic forwarding shortcut.

**Correction and expiry:** D16/D17 source fences invalidate preview derivatives, rendered text/grids/thumbnails, in-progress jobs and definitely-unsubmitted dependent material under existing contracts. Independent official CRM/giving/Document Studio artifacts keep their own identity and retention. A Support attachment can reference a shared physical byte object without gaining authority to delete another owner's logical document.

**History:** file access/generation events remain file/technical history. Support source evidence remains visible only through the canonical currently authorized original. P6 communication history records actual communication effects, not a new event every time a preview is opened. CRM receives no duplicate person/task/Activity record.

## CRM journey and consequential actions

Staff can enter Support from a CRM record, open a currently permitted original attachment, inspect the exact qualified rendition and return to that CRM context. A Support/CRM association does not unlock a care file, financial record or another source conversation. Unknown requesters, shared addresses and represented organizations retain their existing distinct identity/linking rules.

A PDF that resembles a receipt is still requester-supplied evidence unless the owning Document/Giving domain identifies an authoritative artifact. A spreadsheet total is still an unverified saved value. Deliberate business work continues through its owner-authorized action and history.
