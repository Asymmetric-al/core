Screenshots and accessibility state were inspected directly. ReUI customizer was opened and closed without changing the selected Base UI/Maia/Zinc values. App Shell20's demonstration width changed temporarily for inspection and was restored; the v3 More menu was opened then dismissed. No hidden application state, cookies, local storage, credentials or source-code bundles were extracted. The inspection establishes visible layout/configuration facts only.

The selected design keeps Core's shell and places a labelled **Reading: Compact** menu beside Find in the conversation reader. This is an Asym product judgment based on the task location; the references do not themselves prove that exact control. A professional result comes from readable hierarchy, stable focus, explicit temporary-versus-saved semantics and complete failure behaviour, not visual copying. Implementation must use the actual shared Base UI/Maia primitives and source/CRM rules described in [R01–R26](phase26-d33-adversarial-review.md).

The founder's examples are therefore used selectively, including explicit negative evidence. No claim of browser QA for the proposed Asym design is made. Actual rendering, accessibility, mobile and staff comprehension remain [release proof](phase26-d33-proof-and-operations.md).
