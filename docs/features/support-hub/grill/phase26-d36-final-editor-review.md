## Material finding F01 — Changed link destination can escape the edited-excerpt marker

**Severity: Medium; likelihood: plausible under the expressly permitted safe-link editing path.** R05 and the UX editing section mark an excerpt Edited when normalized text changes and exempt formatting-only changes. They also allow safe links. A staff member can change a link destination while preserving its visible label, leaving canonical plain text unchanged. The rendered quote could then appear as an unchanged excerpt from the original sender even though the destination was supplied by the staff member. Validation that a URL is technically safe does not make it the source author's original URL.

This narrows the attribution rule, not the selected A/default or editing freedom. The permanent fix is to include changes to meaningful link destinations in the existing comparison. Do not prohibit ordinary in-place link editing or add a separate confirmation.

**Exact amendment:** “Any change to the quote's canonical text or meaningful link destinations produces recipient-visible Edited excerpt attribution. Presentation-only formatting changes are exempt. Qualified Undo to the exact originally inserted canonical text and destinations may restore the initial label.”

**Exact acceptance addition to P06:** “Changing a quoted link destination while retaining identical visible text produces Edited excerpt in composer, HTML and plain text. Restoring the original destination/text through qualified Undo restores the original label. Cosmetic link styling alone does not trigger the label.”

The comparison can use the already qualified canonical text and meaningful links, not DOM HTML or a semantic AI classifier. Quote source identity remains server-derived and unchanged.
