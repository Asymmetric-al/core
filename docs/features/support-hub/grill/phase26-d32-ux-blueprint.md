## Entry and ordinary journey

Maya is responding to a donor-care inquiry with a screenshot, Word document and spreadsheet attached. The example tests the journey; it does not establish the prevalence of those files or access to restricted financial/care records.

1. **Find the attachment on its message.** Show a compact card with permitted name, actual type/size and availability. Keep source/message identity available so two `details.xlsx` files are not confused. A label such as **Checking file** reflects real hygiene state; metadata count alone cannot say it is ready.
2. **Choose Preview.** Use an explicit labelled action when eligible. No file is converted or opened solely because Maya opened the conversation or searched its filename. A separate **Download original** action is available only when authorized. Unsupported preview does not automatically invoke it.
3. **Keep working while it prepares.** Open the reader shell immediately with filename/source identity and a calm status. Generation can continue in the background while she closes the shell and works on her reply. Do not freeze the conversation, erase a draft, display fake percentages or send completion mail.
4. **Read the qualified result.** Display one content area with the appropriate small toolbar. A thin **Preview** context label distinguishes it from the original. A short limitation strip appears only when material known omissions exist, with **Details** for the coverage manifest. Technical parser/library names stay out of ordinary UI.
5. **Use the original when needed.** Download original retains original bytes; it never downloads a converted substitute under the original name. No extra automatic file reuse/forward/share action is introduced. The OS/browser may handle a deliberate download according to user settings; Asym does not promise control over that external copy.
6. **Close and continue.** Escape or Close returns to the exact attachment card and conversation position, with the unsent TipTap draft, recipients, chosen work intent and CRM return path intact. Closing does not mark the file reviewed, change status or complete the underlying request.

The desktop reader is one generous modal/dialog using the existing shared pattern, not a tiny tooltip or a permanent multi-pane document workspace. Its persistent header contains close/back, filename and source context; its footer/header provides Download original only where permitted. Format-specific navigation remains consistent in placement. The conversation stays mounted behind it; no independent copy of work or draft is made.

On mobile, the same reader becomes a full-height surface with stable close/back and reachable controls. It is usable with portrait layout and the virtual keyboard. Essential information wraps rather than truncating file identity into indistinguishable names. An optional next/previous attachment control stays limited to the invoking message and rechecks every file's current access; no cross-conversation gallery or File Manager is created.

## Documents and slides

Show the first ready page/slide at a readable fit and provide page/slide count, previous/next, direct navigation, zoom and reset. Bound neighboring-page loading. Source numbering remains visible when slides are omitted; slide3 must not be silently relabelled slide2. Text reading mode represents the same qualified content and coverage, not an independent summary or canonical accessible-document export.

DOCX wording should say **Reading preview** and, when relevant, **Revision markup and comments are not shown**, with **Pending revisions remain in the original** in details. No-markup presentation displays the resulting final-text reading view; it does not accept edits in the source or mean that pending revisions are absent. PPTX can say **Static slides · animation and speaker notes are not shown**. A detected missing linked image or font substitution can materially alter meaning and must appear in the limitations, or block the preview if the profile cannot keep it useful and legible.

The renderer must not quietly fetch a linked image from the internet to improve appearance. It must not insert missing data, recalculate document fields or make an absent chart look like a valid blank. The original remains the source for inspection outside the bounded preview when authorized.

For a PDF, no **Verified**, **Official** or signature-valid indicator is inferred from visual appearance. Some documents have no useful text layer; the reader says **No searchable text in this preview** and does not silently enable OCR. Dynamic forms or encrypted files outside the profile do not prompt for a password or fall through to an external viewer service.

## Spreadsheet journey

The XLSX view is deliberately a sheet/value reader rather than a print preview:

1. Open on the first visible sheet in original order. Show a compact sheet selector and preserve its source name. All-hidden and empty workbooks have distinct states. Hidden sheet names need not be listed; a permitted count/notice explains omitted content.
2. Show original row and column coordinates. Hidden/filtered rows and columns remain omitted; visible coordinates retain gaps instead of renumbering data. Sparse worksheets are rendered in bounded windows, not a dense rectangle allocated from a huge declared dimension.
3. Use saved typed cell data. When a formula has a cached result, display that saved result with a persistent **Saved values · not recalculated** context. A formula with no cached result shows **Saved result unavailable**, not a false zero. A genuinely empty cell is still empty.
4. Selecting a cell opens a small detail area with coordinate, displayed/saved raw value and optional escaped formula text. Leading zeros, large integer strings, decimal precision, source workbook date system and unsupported formatting remain distinguishable. This is not an editable formula bar.
5. Unsupported chart/image/comment/formatting features are disclosed. Pivot definitions, refresh and interactivity are omitted, but visible saved pivot-result cells stay in the grid as saved values; no cache is refreshed. Do not substitute a PDF print range or claim the grid represents every hidden/formatted aspect of the workbook. No sorting/filtering/recalculation/import/task completion is added. The existing visible/hidden source state remains the basis.

Provide an accessible paged/table or cell-detail reading path over the **same represented values**, with proper headers/coordinates, rather than hiding them behind mouse-only virtualization. Paging maintains source coordinates and does not become a second data export. The raw workbook's financial-looking values are unverified attachment data; no giving or CRM write is derived from them.

## Text and CSV journey

TXT is readable selectable text with a wrap control, line references where useful and Find in this preview. Filenames, XML-like text, HTML tags, formulas and links remain escaped/inert. Do not let text content alter the app DOM or create navigation.

CSV opens with visible **Delimiter: Comma**. Staff may select Semicolon or Tab for this view, see the newly parsed result, or choose **View as text**. This handles international files without a preference hierarchy, import wizard or ambiguous automatic inference. The selection is a new projection input and cannot accidentally reuse a comma-parsed cached grid.

Do not assume the first record is a header and remove it; display row1 unless a later separately justified feature explicitly chooses headers. Preserve quoted embedded line breaks, trailing empty fields, leading zeros and every formula-looking cell literally. Malformed or inconsistent quoting/rows makes the table unavailable with original text available when its independent encoding/size checks pass. Never shift values into a guessed column layout.

## Find, links and copying

**Find in this preview** searches the entire declared currently authorized represented content of this one file, including pages/sheets not yet displayed; it does not search hidden/comment content, other attachments or all conversations. Results state coverage limits and retain coordinates/pages. **No matches** is shown only after that represented scope is completely searched; incomplete retrieval says **Search incomplete** and offers retry. Image-only content is labelled nonsearchable. A saved spreadsheet value is searched as represented; no formula calculation or AI extraction is involved. Query telemetry does not retain private terms.

Links inside documents remain inert until a separately qualified existing link-handling path permits a deliberate action; no parser or viewer automatically navigates or loads a URL. No new external-link inspector or authenticated URL broker is added solely for C. Ordinary selectable text/copy behavior follows current content policy; the product cannot promise that readable content is impossible to copy or screenshot. It adds no bulk extraction/export button.

## Failure and state language

| Condition                                    | Staff-facing behavior                                                                                                                                 |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Safe metadata only; bytes/scan not qualified | **Checking file** or source-specific unavailable state. No Preview/Download bypass.                                                                   |
| Eligible generation queued/running           | **Preparing preview**; keep the surrounding work usable. Close/return does not create a new job.                                                      |
| Supported qualified complete profile result  | Show the reader with ordinary Preview identity; no claim that the original is authoritative business truth.                                           |
| Known material omissions                     | **Limited preview** plus concise cause and expandable coverage details; original remains distinct.                                                    |
| Unsupported format or features               | **Preview isn’t available for this file**; Download original only if independently allowed.                                                           |
| Resource ceiling exceeded                    | **This file exceeds the preview limit** with relevant user-safe size/page explanation; no silent partial result labelled complete.                    |
| Deterministic corrupt/unparseable input      | Explain unavailable preview without pretending the source bytes are missing. No automatic retry loop.                                                 |
| Transient generation failure                 | Safe **Couldn’t prepare preview** status and a qualified retry path within the existing intent allowance. No blind new request after unknown success. |
| Source removed/expired/reclassified          | Invalidate future reads and the current viewer; show a nonsensitive source state. No old preview/download URL remains an escape.                      |
| Access revoked/tenant switched               | Close or replace restricted content, clear inappropriate retained state and provide safe return navigation. No hidden filename/count leak.            |
| Download not permitted                       | Do not suggest Download as the repair for a renderer or safety failure.                                                                               |

No error messages expose raw storage keys, service credentials, source URLs or parser stack traces. Same-source rechecks also apply during page/range loads and to a result that was generated earlier by another worker.

## CRM and authoring continuity

Entering from a CRM Support row opens the same currently permitted original message/file. Return closes the viewer, restores the Support detail, and then returns to the originating CRM record. No file is copied onto every person/organization related to the conversation. CRM access alone never grants Support bytes; a Support assignee does not gain restricted CRM, finance or missionary context.

A draft's newly selected local file and an admitted message attachment are different states. Existing D18/D23 upload and source/asset qualification must finish before a reusable preview/download exists; the metadata-only current `local:` staging stub is not an implementation. This decision does not waive real upload/send qualification. Viewing an attachment never inserts its original or preview into TipTap. Deliberate future Attach/Reuse actions retain their existing identity, permission and audience review.

## Visual craft and accessibility

Use Maia geometry, shared semantic tokens, clear typography and a single consistent reader shell. Use restrained borders, readable source identity and a short toolbar; do not crowd ordinary inspection with engine versions, full retention policies or a dashboard of file metadata. Coverage and actual failure information must remain easy to find, not hidden in a tooltip. Distinguish literal file type from verified eligibility.

Meet WCAG2.2 AA for app controls and content presentation that the product owns. Test visible keyboard focus, logical reading order, labels, current-page/sheet announcements, Escape/Close return, 200% text zoom,320-CSS-pixel reflow of chrome, high contrast, both themes and reduced motion. Provide buttons for pan/zoom/rotate navigation where gestures exist. Preserve legitimate image aspect and permit two-dimensional content scrolling without making the surrounding controls require horizontal scrolling. Touch targets use the shared accessible geometry; no color-only status or hover-only information.

Source accessibility limits are reported honestly: scanned pages may have no text; a source image may have no description; reading-order extraction may be insufficient. No fabricated alternative text or unverified automatic transcript is inserted. That does not excuse unusable controls or a grid with no equivalent accessible way to inspect its represented values. [W3C grid guidance](https://www.w3.org/WAI/ARIA/apg/patterns/grid/) informs interactive navigation; a read-only table should use simpler semantic table behavior when sufficient.

## Maintenance journey

Staff manage no renderer settings or converter account. The shared file/preview owner maintains one versioned format profile, qualified test corpus and dependency/security/cleanup controls. Changes affect new renditions, never the original file or a completed business record. An unsafe profile can be disabled centrally without disabling all Support work or weakening file restrictions. Tenants retain their existing file/content policy owner; C adds no admin extension editor.

All actual format, sandbox, private-range access, mobile/assistive-technology and staff-task tests in [P01–P40](phase26-d32-proof-and-operations.md) remain required. This blueprint is complete design documentation, not evidence of a tested perfect UI.
