- Current message/conversation IDs are TEXT, author/body are JSONB, and the inspected API/collection does not define a qualified current-head/revision operation. Broad grants and existing tenant/staff RLS are not sufficient original-author controls.
- Current addPrivateNote creates another message and bumps conversation facts. It is the wrong mutation path for correction, no-op, history or cancellation.
- The current PrivateNote renderer has no edit/history controls and can use HTML fallback. It is a scaffold, not canonical-body/author or accessible-UX authority.

## Technical primary evidence and chosen architecture

[PostgreSQL17 policy semantics](https://www.postgresql.org/docs/17/sql-createpolicy.html) distinguish old/new row predicates and applicable USING fallback; [locking](https://www.postgresql.org/docs/17/explicit-locking.html) and [isolation](https://www.postgresql.org/docs/17/transaction-iso.html) support a conditional atomic mutation, not a lock held while a person edits. [Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security) and [current changelog](https://supabase.com/changelog) distinguish grants/exposure/service authority. The skill's unconditional claim that omitted WITH CHECK permits ownership reassignment is too broad; primary semantics control. The markdown changelog fetch was unsupported by the web reader; the official HTML source was used. No schema, key or production record was touched.

[Tiptap content checking](https://tiptap.dev/docs/guides/invalid-schema) is useful but does not replace complete original JSON/profile validation before lossy normalization. [Snapshot history](https://tiptap.dev/docs/collaboration/documents/snapshot) belongs to a broader collaboration service; adding it solely for this narrow source revision would introduce unnecessary dependencies. [React performance](https://tiptap.dev/docs/guides/performance) and [Next integration](https://tiptap.dev/docs/editor/getting-started/install/nextjs) support isolating a deliberate editor and static history rather than mounting editors throughout the timeline. No unrelated React/Next upgrade is selected.
