## Required correction FUX01 — Pending local attachment must participate in navigation safety

**Failure and importance:** R10 can acknowledge saved text and an attachment manifest while the file's bytes remain local/in flight. R13 then guards only an unmount of dirty writing; R18 and P26 correctly say uploaded bytes are separate but do not explicitly stop a clean text editor with a pending File from navigating away and losing that file. A resumed manifest cannot reconstruct missing local bytes. This can lose a user's attachment without a deliberate choice even while the text status says Saved.

**Severity:** High data-loss impact for that attachment. **Likelihood:** Plausible on slow/mobile networks; a deterministic possible state under the proposed separate text/upload handling. No executed Asym upload loss is claimed.

**Effect on A:** Amends navigation/attachment custody; does not invalidate the finder or justify offline storage, persistent hidden editors or a new upload service.

**Exact permanent language to incorporate:** “Supported navigation that would abandon local-only attachment data is guarded even when the text/draft bundle is acknowledged. Continue the existing qualified upload independently when its owner safely supports that navigation; otherwise wait/Retry/Stay or explicitly leave without the unfinished attachment. Keep safe saved writing and a truthful unavailable/reselection state where useful. A pending file marker is not recoverable file bytes. Late upload completion cannot reattach to a changed, discarded, consumed or unauthorized draft generation.”

Apply to R13/R18, the UX navigation/upload states, and P16/P26; preserve existing source authorization and conditional draft-save semantics.

## Documentation alignment FUX02 — Title-only finder search

The final R05/P04/C09 consistently choose permitted conversation-title search under existing source index eligibility. UX research still says “Search conversation titles and references” and “title/reference” in its journey. Narrow these historical proposed phrases to title-only or explicitly mark them superseded. Do not broaden final scope to implement reference matching merely for internal consistency.

**Severity:** Low documentary implementability risk. **Likelihood:** Plausible conflicting interpretation if an implementer uses the linked research. **Effect:** Alignment only, not a new preference or feature.
