## Residual controls after qualification

These controls are proposed as part of D40. Assign actual accountable teams/people before activation. O02/O04/O05 numerical alert policies are engineering/product judgments, not vendor constants. Coverage, authorization, exact input timing, custody and correctness are release gates; monitoring is not their substitute.
