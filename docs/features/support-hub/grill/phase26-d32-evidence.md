## Technical findings that change the permanent path

**A spreadsheet PDF is not automatically a workbook preview.** LibreOffice export settings can include hidden sheets and ignore print ranges; ordinary printing can instead omit data. Therefore D32 uses a visible saved-value grid for XLSX. [LibreOffice PDF export](https://help.libreoffice.org/latest/en-US/text/shared/01/ref_pdf_export_general.html).

**Cached formula results are historical values, not freshness evidence.** Microsoft documents that SpreadsheetML stores an optional cached result beside the formula. D32 preserves that value, reports missing cache and does not calculate or refresh external inputs. A test can deliberately contain a stale saved result; the product cannot determine arbitrary freshness without authority it does not have. [Microsoft formula/cell-value reference](https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/working-with-formulas), updated 14 January 2025.

**Conversion success can omit material.** Current Gotenberg documentation says external linked content is dropped from untrusted Office inputs even when conversion succeeds. Its defaults and broad format list are not Asym's profile. Detect relevant features and report limitations or refuse misleading output; never weaken egress restrictions to repair appearance. [Gotenberg Office conversion](https://gotenberg.dev/docs/convert-with-libreoffice/convert-to-pdf), [configuration](https://gotenberg.dev/docs/configuration).

**DocRaptor is a different input/authority path.** Its API accepts HTML/XML content to generate PDF/Excel outputs. That does not qualify arbitrary received DOCX/XLSX conversion, nor override P18's renderer contest. [DocRaptor API](https://docraptor.com/documentation/api).

**Parsing requires isolation and layered validation.** OWASP documents spoofed MIME, parser vulnerabilities, active content and decompression/XML/resource attacks. D32 validates actual type/structure, isolates processes and denies egress in addition to scanning. File extension, a clean scan or a successful renderer alone does not prove safe processing. [OWASP file upload guidance](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html).

**Viewer software must be maintained and constrained.** PDF.js has documented historical malicious-PDF execution vulnerabilities; the cited 2024 issue was patched and does not establish a current vulnerability in Core. It demonstrates why a browser worker is not an isolation or patching strategy by itself. [Mozilla advisory](https://github.com/mozilla/pdf.js/security/advisories/GHSA-wgrm-67xf-hhpq), [PDF.js FAQ](https://github.com/mozilla/pdf.js/wiki/Frequently-Asked-Questions).

**Typed visible data and accessible navigation matter.** W3C's grid pattern describes coordinated keyboard focus for interactive grids; simple table semantics remain preferable where sufficient. A canvas cannot be called an accessible copy of an arbitrary scan. The same represented values need a real keyboard/AT reading route. [W3C grid pattern](https://www.w3.org/WAI/ARIA/apg/patterns/grid/).

**Supabase grants and source access are independent.** Current Storage/RLS documentation and the breaking-change index were checked. Storage policies, service-role bypass, public delivery and API grants need explicit qualification alongside source authorization. No platform upgrade is made here. [Storage access](https://supabase.com/docs/guides/storage/security/access-control), [RLS](https://supabase.com/docs/guides/database/postgres/row-level-security), [current breaking changes](https://supabase.com/changelog?types=breaking-change).
