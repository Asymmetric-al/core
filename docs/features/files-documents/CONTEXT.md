# Files and Documents

Language for shared document custody and source-owned private document requests.
Specialized document identities remain in their owning domain glossaries.

## Language

**Private Document Request**:
A source-owned request for a particular recipient to supply documents for a
stated purpose. It is distinct from its invitation, submissions, review and the
source's decision that a requirement has been satisfied.
_Avoid_: upload folder, file link, workflow run, accepted evidence

**Document Request Recipient Authority**:
The requesting source's current designation of the intended recipient and the
actions that recipient may perform for one Private Document Request. It does
not imply organization membership, a donor relationship or access to other work.
_Avoid_: email match, file ownership, folder membership, general guest role

**Document Request Recipient Confirmation**:
Evidence that the intended recipient has met the proof required for one Private
Document Request. Ordinary email confirmation establishes control of the
addressed mailbox, not legal identity, representation or document acceptance.
_Avoid_: identity verified, email verified forever, approved document, signature

**Request-only Access**:
Current permission to perform the source-approved actions for one Private
Document Request without enrolling in the organization's broader product roles.
It does not include other requests, previous submissions or document reading
unless the source separately admits those actions.
_Avoid_: portal membership, public access, generic file sharing, anonymous access

**File Purpose**:
The source-owned Asym work, reusable resource role or continuing obligation
that justifies one use of stored material. It can exist before active placement
or after active use ends, and supplies no permission by itself.
_Avoid_: folder label, personal storage entitlement, currently published use only

**Document Records Policy**:
A tenant-owned policy for retention, review and disposal of specified ordinary document records and uses, subject to their applicable obligations. It is distinct from an individual record’s policy assignment, a hold and permission to access the records.
_Avoid_: access policy, legal certification, deletion timer

**Partner Document Reference**:
An independently admitted, source-owned use of specified document evidence for ongoing work with a particular partner. It is distinct from the original collection record, a sharing permission, and a determination that an agreement is valid or current.
_Avoid_: reference letter, bookmark, active agreement

**Submission Confirmation**:
The source's record that an exact file version or Document Assembly was durably received for a Private Document Request. It does not mean the received material is safe to preview or that the requested business evidence has been accepted.
_Avoid_: donation receipt, approved evidence, upload progress, preview Ready

**Submitted File Preview**:
A qualified read-only representation of the exact file version received for a
Private Document Request, available only under its current source permission.
It preserves its declared coverage and is distinct from the original or an
official generated document.
_Avoid_: personal drive, original download, latest file, accepted document

**Document Request Item**:
A source-defined piece of requested document work whose submission and review
outcome are tracked within a Private Document Request. It can involve several
supporting files and is distinct from the overall request.
_Avoid_: file count, folder, upload attempt, whole request

**Submission Correction**:
A later submission offered to correct a specified earlier submission for the
same Document Request Item while preserving the earlier received act. It is
distinct from evidence acceptance, deletion and changes to other uses of the file.
_Avoid_: overwrite, replace everywhere, undo submission, approved replacement

**Submitted Original**:
The immutable bytes received for a particular submission to a Private Document
Request, including a corrected submission. It is distinct from the first
historical attempt, a preview, a submission summary or a processed alternative.
_Avoid_: first file, latest file, rendered copy, accepted evidence

**Submission History**:
A source-authorized record of durably received submissions and correction
relationships for a Document Request Item. It is distinct from file contents,
current-file permission and internal audit history.
_Avoid_: file archive, audit log, upload progress, list of all previous files

**Completed Request Access**:
The source-authorized, time-bounded ability to read permitted results of a
normally fulfilled Private Document Request. It is distinct from fulfillment
itself, permission to submit or correct files, and retention of the evidence.
_Avoid_: permanent archive, completed task, retained file, renewed session

**Fresh Completed Request Access**:
A separately source-authorized, finite read-only admission to an eligible
portion of the same recipient's original completed-request scope after its
ordinary access period ended. It is distinct from extending the ended admission,
repairing sign-in or reopening the request.
_Avoid_: reset expiry, resent link, reopened request, restored file

**Document Request Due Date**:
The requesting source's requested-by target for specified recipient submission
work on an ordinary Private Document Request. It is distinct from a binding
submission cutoff, recipient access end, review target or fulfillment.
_Avoid_: access expiry, automatic rejection, review completion date

**Unfinished Request Access Deadline**:
The finite source-owned boundary for recipient access while an ordinary
Private Document Request remains unfulfilled. It is distinct from the requested
due date and from an overall limit that also binds Completed Request Access.
_Avoid_: submission due date, staff review target, automatic completion, universal overall expiry

**Document Request Access Issuance**:
The requesting source's act of first making original, purpose-bound request
access available to its intended recipient, subject to required confirmation
and current permission. It is distinct from creating the request, issuing an
entry credential, delivering an invitation or fulfilling the request.
_Avoid_: email sent, link created, first visit, account enrollment, request completed

**Fresh Unfinished Request Access**:
A separately source-authorized, finite admission for the same intended recipient
to continue currently permitted work for the original purpose of a still-unfinished
Private Document Request after ordinary access expired, within the source-approved
requirement lineage, including additions only when explicitly admitted by a
qualified prospective amendment. It is distinct from changing the ended admission,
repairing sign-in or reopening completed work.
_Avoid_: reset expiry, resent link, reopened request, automatic renewal

**Document Request Item Acceptance**:
The requesting source's record of a deliberate, authorized staff decision to
accept specified submitted evidence for a Document Request Item's stated
requirement and purpose. It is distinct from receipt, technical safety,
current satisfaction of all source conditions, whole-request fulfillment and
approval for another use.
_Avoid_: approved file, upload success, preview ready, request complete, verified authenticity

**Document Request Item Acceptance Correction**:
The requesting source's attributed record that a specified earlier Document Request Item Acceptance was made in error, together with its current source consequences. It preserves the original decision and is distinct from Submission Correction, Request changes, deletion and request reopening.
_Avoid_: unaccept toggle, undo acceptance, Submission Correction, request reopening, deleted evidence

**Document Request Fulfillment**:
The requesting source's durable record that an eligible Private Document
Request satisfied its complete requirements on a specified source and evidence
basis at an actual source occurrence. It is distinct from submission receipt,
individual item acceptance, generic task completion, approval of a larger
process and permission to read the completed request.
_Avoid_: all files uploaded, all visible items accepted, completed task, access granted

**Document Review Responsibility**:
The requesting source's designation of the person or team route accountable
for specified pending ordinary document-review work. It is distinct from
permission to inspect or decide, the human who records a review decision,
and the participant's contact or help route.
_Avoid_: access grant, actual reviewer, task assignee, participant contact, team account

**Staff-supplied Document Evidence**:
An exact file version or Document Assembly deliberately supplied by authorized staff for a Document Request Item, with attribution to that staff act. It is distinct from a participant's submission or affirmation, item acceptance and permission for other uses.
_Avoid_: submitted by the participant, copied approval, reused consent, file ownership

**Document Request Clarification**:
A source-owned text question or reply about a Document Request Item, shared
between its currently authorized recipient and authorized staff for that
request purpose. It is distinct from internal review notes, file submission
or correction, a formal Request changes decision and evidence acceptance.
_Avoid_: file-wide chat, staff note, evidence acceptance, request approval

**Document Request Cancellation**:
The requesting source's deliberate terminal decision to end an issued unfinished
ordinary Private Document Request without fulfillment. It preserves prior source
facts and independently required work, and is distinct from evidence rejection,
deletion, access expiry or cancellation of an enclosing process.
_Avoid_: fulfilled request, rejected document, deleted file, expired link, canceled application

**Document Request Item Instruction Revision**:
An attributable, source-published version of the participant-facing instructions
for one Document Request Item. It distinguishes current instructions from the
basis of an earlier submission or review and is distinct from a submitted file
version, Submission Correction or review decision.
_Avoid_: latest file, corrected submission, review approval, overwritten instructions

**Document Request Template**:
A reusable, source-owned set of ordinary Document Request Item definitions and
instructions used to prepare an independent, never-issued request draft.
It is distinct from an issued request, submitted evidence, an access grant and
an executable workflow or form definition.
_Avoid_: live request, copied evidence, inherited approval, access grant, executable workflow

**Private Document Share**:
A source-authorized, finite permission for a named recipient to read specified
private document material for a stated purpose through explicitly permitted
actions. It is distinct from an invitation, recipient confirmation, a collection
request, retention and permission to alter or reshare the material.
_Avoid_: anyone link, file ownership, folder membership, request-only access, proof of reading

**Document Review Comment**:
A source-owned staff observation about an exact document use and file version,
optionally associated with a supported location. It is distinct from comments
embedded in the original, a participant message and a review decision.
_Avoid_: embedded annotation, participant message, review decision

**Submission Withdrawal**:
A source-owned act that removes an exact received contribution from current consideration for a Document Request Item while preserving its received history and applicable obligations. It is distinct from file deletion, requirement waiver, request cancellation and reversal of acceptance.
_Avoid_: file deletion, requirement waiver, request cancellation, acceptance reversal

**Document Request Reminder Plan**:
A source-owned, bounded arrangement governing whether and when automatic reminders may be issued for outstanding recipient work on one Document Request. It is distinct from a reminder message, a delivery attempt, the Requested by target and recipient access.
_Avoid_: reminder message, delivery attempt, Requested by target, recipient access

**Document Request Replacement**:
A source-authorized new request issued for a different intended recipient in place of an eligible prior request, with an explicit relationship preserving each request's identity and history. It is distinct from draft preparation, an address edit, reopening, or transfer of earlier evidence or access.
_Avoid_: draft preparation, address edit, reopening, evidence transfer, access transfer

**Document Review Attention Request**:
A source-owned staff request to bring an exact Document Review Comment revision to one eligible colleague’s attention. It is distinct from the comment, notification presentation, review responsibility, access permission and evidence acceptance.
_Avoid_: comment, notification presentation, review assignment, access grant, evidence acceptance

**Document Assembly**:
A source-owned contribution that presents an ordered set of selected image originals as one assembled document. It preserves the identity of its originals and assembled output and is distinct from a Document Request Item, an original file, a preview and item acceptance.
_Avoid_: original file, preview, request item, accepted evidence, merged history
