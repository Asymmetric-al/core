## Verdict

**Accept with required amendments.** The complete copied item set, its selected definition basis, new draft/item identities, source attribution, history and recoverable operation outcome must agree. A reusable definition is neither an issued requirement nor portable authorization. Template editing/retirement changes future template use; a successfully copied draft has independent content and later source qualification.

The highest risks are mundane copying mistakes: importing prior recipient/evidence/grant fields; reading a live template pointer after staff reviewed another revision; committing half the item set or losing history; retrying after retirement as a new copy; using broad template-admin/service privileges instead of the target source's rights; and making a known committed copy falsely look failed after its draft was edited or issued. These do not require a generic workflow/versioning platform to fix.

### Current primary technical guidance

- [PostgreSQL17 CREATE POLICY](https://www.postgresql.org/docs/17/sql-createpolicy.html): applicable SELECT/INSERT/UPDATE policies interact for UPSERT; old-row visibility and new-row checks must be satisfied, with permissive/restrictive composition assessed together. Checking only one USING expression is insufficient.
- [PostgreSQL17 transaction isolation](https://www.postgresql.org/docs/17/transaction-iso.html): Read Committed statements can observe different committed states; a locking operation that waits can receive an updated row. This supports rechecking actual expected basis and eligibility after waits. No specific lock schema or global serializable transaction is prescribed here.
- [Supabase views](https://supabase.com/docs/guides/database/views) and [RLS](https://supabase.com/docs/guides/database/postgres/row-level-security): view-owner versus invoker behavior and service/owner bypass must be explicitly qualified, along with grants. These mechanisms do not supply source-specific content or operation authority.
- [Payload Local API](https://payloadcms.com/docs/local-api/overview): Local API access override defaults true; passing a request/user is distinct from enforcing collection access. Transaction/lock behavior also has explicit options. If CMS machinery is reused, native configuration and all hooks must be proved rather than assuming request propagation establishes authorization or atomicity.

These technical rules support the safeguards below. No provider/account operation or toy SQL experiment was needed: a mock transaction or isolated clone test cannot prove the actual proposed source semantics and role paths.

## Practical limits and operational response

No numeric quota is imported from email templates, PDF publication, Workflow Studio or prior preview/search profiles. A small source-owned implementation need not add scheduled template review, automatic expiration, a generic compiler, a separate projection bus or a new billing governor.

Ordinary recovery should remain available after a toast disappears:

- Failed/unknown Apply reconciles its original operation. A known complete draft is opened under its current source rights; unknown is not new-copy permission.
- A stale selection preserves lawful draft content and lets staff deliberately choose current eligible material or continue ordinary authoring. It does not silently use a latest template or start a new access period.
- Wrong reusable content is corrected by an authorized maintainer through a new current definition; future availability can be stopped. Existing copies are not bulk-amended. Where a specific issued request truly needs correction, its actual eligible Q33/Q34/Q36/Q37/source route is used.
- Mistaken retirement has a current qualified maintainer repair/re-enable path if that capability is supported, without changing original retired history or resurrecting disposed/private content. No universal Restore or approval bypass is inferred.
- A temporarily failed optional catalog/search projection does not erase valid drafts or reinterpret source issue state. Stop affected new use until the source truth is available; ordinary independently authorized authoring remains.
