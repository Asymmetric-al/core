## Exact recommended corrected decision

Require the current qualified source/P12 action, exact target/work scope and relevant current basis; generic staff/reviewer/task/assignment/read/grant-administration powers are insufficient. This is not a new date hierarchy, per-item inheritance designer or bulk amendment. The complete current source decides whether recipient work remains; already received material awaiting scanning or staff review alone is not such work.

Permit a lawful earlier or later target, including an already-past target where the source permits that current plan, without backdating its effect. Permit setting a proved absent optional target and deliberately clearing an explicitly source-optional target. Do not clear a required target or treat unknown/malformed/missing provenance as absence. Preserve the source's declared temporal form. A civil-date target is a date in the captured source-declared IANA zone and qualified calendar meaning: compare trusted receipt's civil date in that interpretation; same target day is not late and a later day is late. An already-qualified instant retains its actual precision and Q09 strictly-later/equality rule. The editor does not silently convert forms, expose a new type/zone policy picker or derive meaning from browser/organization defaults. Preserve enough original interpretation evidence to explain history after timezone-rule changes.

A successful edit is prospective from its real durable source occurrence. It records the prior/current target, exact applicability and trusted actor without rewriting receipts, historical timing, submitted-under terms, evidence, review decisions, instructions or access. Q09-compatible target-only changes can resolve at first submission admission without changing immutable submitted intent or forcing new bytes/proof. Once receipt is admitted, later retries and target edits preserve that receipt's original terms or explicit unresolved timing. Separately admitted new/revised work gets only its actual source-qualified applicability, not unrelated historical lateness or a new interval.

All fixed original/fresh/completed access ends, independent hard cutoffs, current proof, restrictions and source completion/cancellation retain their own rules. A target beyond access end is a mismatch to explain rather than an automatic target-only denial or extension. Editing a coordination target need not issue access or require the participant online; any actual recipient action still needs current authority. A target edit creates no new review coverage, first-issuance gate, waiver, acceptance, fulfillment or notification.

Commit the target revision, applicability/history and required durable source follow-through coherently at the existing authoritative boundary. Order relevant target/source/receipt/terminal/permission races; preserve independent unaffected work. Matching committed operations reconcile before new-command eligibility/no-op, under current result disclosure. A stale basis conflicts even if values match after an intervening change. Only a currently qualified unchanged value is a no-op. Unknown commitment needs same-operation recovery, not a new key, stale overwrite or automatic retry of a different plan.

Keep one accessible contextual edit with a clear current/proposed value, actual target/access meaning, deliberate Save/Cancel, truthful outcomes and preserved safe input. Correct a mistaken saved target through a new current qualified edit while eligible, including choosing the old value when lawful; never roll back history. After eligibility ends, use an actual governed source fact-correction/remediation path without fabricating recipient work, reopening, cloning requests or falsifying historical receipt terms. Current source projections and independently qualified existing communication follow their owners; Q46 authorizes no new send, cadence or automatic reminder rescheduling and imposes no blanket stop on unrelated effects. Preserve current privacy/retention, native every-writer enforcement, bounded operations, compatible rollout/restore and real-role/race/locale/browser/AT proof before activation. Existing Due Date terminology suffices; formal owner/OpenSpec adoption and implementation remain separate stages.

## Minimal lifecycle and operational correction

A draft input or date-picker selection changes nothing authoritative. Cancel leaves the current target. A deliberate Save is rejected/conflicted, durably accepted, qualified unchanged, or unknown to the observer. Only accepted source change alters current applicability. These are operation outcomes, not a new giant request-status enum.

Current target can be present or proved optional absent; unavailable, invalid and unknown provenance are different. Request lifecycle, current recipient work, evidence receipt/review, technical availability and source access retain their own dimensions. Date edits do not manufacture any of them.

One exact current target/work scope is authoritative; old revisions remain lawful historical facts under source retention. An accidental current value can be replaced through the same authorized editor while eligible. A new edit choosing an earlier value is a successor, not restoration of an old epoch. If the request has no remaining recipient work or is terminal, a meaningful factual-error/remediation record and actual source repair authority are the route; a new ordinary request cannot repair a false historical target. Required repair must be reachable before enabling the supported journey, not a future Contact admin promise.

Minimal monitored controls: any unauthorized edit/disclosure, historical applicability drift, duplicate/reapplied edit, false recipient-overdue or rights reset is an immediate source-owner containment/investigation event. Unknown operations beyond the declared reconciliation bound need owned source recovery, not automatic new edits. Query/lock/history budgets and user-comprehension/accessibility failures block rollout until fixed and requalified. Budget values must be measured for the actual cohort; this review invents no global number.
