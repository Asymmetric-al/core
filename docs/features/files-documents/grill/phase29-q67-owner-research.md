## Recommendation and genuine remaining choice

**Recommend A: allow an authorized source actor to record that an already-defined, supported external business event actually occurred, including its source-required date and sufficient evidence, through the owning source's contextual command.** Existing qualified native/system/integration producers remain usable. A does not make every staff member or policy editor an event authority.

The strongest alternative, **B: accept occurrences only from qualified native/system/integration producers**, reduces a new class of human-entry error and can be simpler when the organization already captures the authoritative event in a reliable system. It costs an integration or a different supported policy when the fact occurs outside Asym and there is no qualified producer. It cannot replace the missing fact with “now,” a guessed native status, a fake completed task or an indefinite retention assumption.

This is a meaningful producer/actor choice distinct from Q66's policy editing. A policy defines which trusted event matters. An occurrence says that this particular event happened for this exact subject at this actual date. Q62/Q66 consume and correct qualified trigger facts; they do not clearly select an initial human external-occurrence producer. If A is selected, that new ordinary source power and its proof/admission/recovery must be explicitly adopted. The mere requirement for trustworthy facts is not evidence the producer already exists.

| -------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| A — Also allow authorized staff to record supported external occurrences (recommended) | Staff with the exact source power record an actual event in its subject/policy context, using sufficient source-required evidence; current source checks accept or reject it.         | Avoids requiring an integration for every real external fact. Needs exact actor/scope/proof, actual-versus-recorded date, correction and duplicate/replay handling.                                    |
| B — Qualified native/system/integration occurrences only                               | The policy waits for its real qualified producer; any existing source command continues under its own contract. This option adds no general records-specific human event-entry route. | Strong when the actual source already owns the event. This recommendation does not choose a legal duration, start event, universal manual approval or new workflow. A conditional illustration is an actual agreement ending outside Asym **only if** the approved ordinary records profile already defines that occurrence, the true source permits the actor/evidence and no other authoritative source is displaced. It is not a finding that GF has such a completed event, that every agreement uses that clock, or that Q65 End means the agreement ended.
