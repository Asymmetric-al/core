# Phase 29 Q45 — Independent UX adversarial review

2026-10-25, Asia/Bangkok. Conrad selected **A+B together**: exact-version staff comments with supported location references and optional point/rectangular-region markers on qualified static PDF/image representations. Q01–Q44 and the existing 26 glossary definitions remain ratified. This note proposes the necessary Q45 amendments; it does not ratify them, publish formal specifications, implement a feature or establish native release readiness. ## Judgment and scope

The combined choice is coherent if the ordinary comment remains the primary interaction: one source-owned comments list, one small composer, useful text and an optional location. Staff can start from the list or deliberately use **Comment here** in a qualified reader. Posting commits the intended exact-version text and location together. A visual marker helps identify a particular detail; it is not a second document editor, new evidence version, review decision, participant message or general conversation service.

The strongest simpler alternative was A alone. It would reduce geometry, representation compatibility and accessible marker-control work while still supporting general and meaningful page/sheet/location comments. Its real cost is descriptive effort and ambiguity on complex images or dense pages. The selected B increment addresses that cost but cannot be declared complete merely because a text fallback exists. Both precise marker authoring and the baseline comment path need qualification. No measured Asym frequency, time saved, error reduction or unchanged bill is known.

The first cohort is the **ordinary Private Document Request source-owned evidence contribution/use and exact original version**, including Q28 evidence only under its origin and target restrictions. Staff review comments surface in existing request/evidence work and the qualified reader; compatible tasks may navigate/project that same source. A new task per note, Party-note threads, universal provider-file comments and participant Q30 conversation are excluded. Source/P12 rules govern each action and audience; a reviewer label, file Read, team membership or administrator title alone is not complete authority.

Illustration only: Elena reviews an inventory PDF. She can write **Date unclear** as a general comment, select a supported page, or mark the particular date on a qualified page. Rui reads the text in the comments list and, when currently qualified, opens its location. If a correction arrives, the comment still identifies the version Elena actually saw. Elena can later correct her own wording, remove an unwanted location, withdraw the note, or restore an accidentally withdrawn note under current authority. None of these operations accepts the inventory or automatically contacts its participant.

## Governing boundaries checked

Founder §10 requires useful business-purpose and exact-version/location review context; §11 separates read, comment and review authority. Q29 paired reading supplies exact reading context, not automatic marker correspondence. Q30 preserves staff comments while separately governing outward item questions/replies; an internal comment cannot be made outward with a visibility toggle. Q21/Q23 retain deliberate review decisions. Current P9 rejects threaded Party-note discussion and assigns tasks their discussion responsibility; this ordinary source collection is not a replacement CRM-note thread.

Published Support D32 R14 permits declared static rendering of existing original annotations; R28 did not authorize a new annotation canvas. Q45 therefore needs an explicit narrow source/reader amendment for new Core markers. D32 R17's disposable Ready rendition ceiling is **24 elapsed hours from first Ready**, subject to earlier source caps. That technical expiry is not a comment-retention period, an authorization grant or permission to preserve a rendition indefinitely. Comment identity must survive lawful technical cleanup without being falsely moved to a new representation. Q38, Q41 and Q44 do not authorize searching internal comment bodies, external disclosure, or adding comment overlays/transcripts to exact-original delivery.

## Fourteen proposed exact amendments

These clauses are product/acceptance proposals, not an implementation schema. Severity means plausible impact if omitted; likelihood means exposure in an ordinary deployed workflow, not a measured incident rate. H = high, M = medium, L = low. None is rated Critical on hypothetical unsupported assumptions.

### U01 — One exact source and current purpose (H / plausible)

Bind each Document Review Comment to one immutable ordinary source contribution/use, exact original version, business purpose and Tenant/environment, with trusted author attribution. Surface the same source collection in the actual evidence/request work and compatible reader/task navigation. Separately qualify create/read/edit/withdraw/restore/operator and disclosure rights through source/P12. General comments remain possible without a location or successful preview where current comment authority permits. File reading and comment reading/writing are distinct. Do not create universal file chat, Party-note threads, a task per note or a participant audience.

### U02 — Supported references mean what they say (H / plausible)

Allow at most one optional current location: a supported typed page/slide/sheet/cell/line reference or a point/rectangle for the separately qualified PDF/image cohort. Whole-version feedback needs none. Keep readable explanatory context useful but do not label unvalidated free text as a verified jump target. Distinguish viewer page identity from printed labels, original slide numbering from omitted slides, declared sheet/cell semantics from a screenshot, and stable text/CSV positions from screen wrapping. Show only currently qualified navigation; otherwise retain lawful context with **Location unavailable**, without guessing a nearby/newer location.

### U03 — One composer and a deliberate coherent Post (M–H / likely without an explicit rule)

Offer **Add comment** in the list and **Comment here** in a qualified reader; the latter pre-fills a draft's exact context. Show the intended file/version and internal source context before Post. Require bounded nonblank plain text that communicates the feedback, with a helpful prompt; a concise **Date unclear** can suffice. Do not add an essay length, mandatory title/reason, AI semantic classifier or standalone empty/color-only pin. Text and optional location commit coherently in one deliberate Post. Typing, pointer movement, tool choice, pan, zoom and draft geometry remain bounded local interaction state with no database writes. Cancel location retains otherwise-lawful text; closing the reader is not Post.

### U04 — Stable representation and bounded marker geometry (H / plausible)

New or moved geometry requires the actual currently qualified static PDF/image mapping for that exact source/version. Bind a declared stable representation/coverage/geometry basis rather than only a disposable generation ID or provider path. Validate one finite point or nondegenerate rectangle, bounds and canonical transformations before and after rounding. Qualify rotation, crop/view box, orientation, zoom, device-pixel ratio and responsive resize. No source byte changes, screenshot/crop copies, arbitrary SVG selectors, freehand ink, automatic text selection/reanchoring, OCR or annotation export are selected. Office output does not enter this marker cohort merely because it can be rendered as pixels.

### U05 — Equal marker functionality without dragging (H / likely for affected users)

Point/region creation, adjustment, removal and navigation must have usable keyboard and non-drag single-pointer equivalents. A two-corner tap/click interaction and accessible movement/size controls are examples; avoid mandatory technical pixel entry or impractically long one-pixel key sequences. An optional general/page note is not equivalent access to a precise region. Use an explicit placement mode so ordinary touch pan/pinch, scroll and selection do not accidentally draw or post. Escape or Cancel location exits the provisional geometry operation without silently losing the comment text. Existing reader interaction remains available.

### U06 — The list remains a complete accessible interface (M–H / likely if marker-only)

Use one semantic comments list with permitted body, author/time, exact-version context and useful location labels; a marker links to that comment rather than becoming another truth. Overlapping markers must remain individually selectable through the list or an accessible chooser without revealing denied counts. Explicit Show location navigates only a qualified target, preserves sensible focus/return, and never changes the review target. A narrow/mobile drawer may use existing Core primitives; opening/closing it neither saves nor withdraws. Keep controls/list/composer usable at 320 CSS pixels, zoom, touch and AT. Avoid auto-focus/auto-scroll on refresh, color-only meaning, excessive live announcements and unnecessary motion; respect reduced motion. Handle Unicode/RTL/IME, long names and time-zone labels without changing original coordinate meaning or posting during composition.

### U07 — Honest save state and private draft recovery (H / plausible)

Distinguish provisional, posting, known posted, failed, unknown and conflicted outcomes. A timeout is not proof of failure or success. Reconcile the original semantic operation under current disclosure before creating a replacement; repeated clicks/retry must not duplicate a comment, while genuinely separate follow-ups may have the same text. Clear working input only after the result is known or a deliberate cancellation. Preserve currently lawful input through recoverable errors/conflicts, but do not silently persist private drafts offline, carry them between tenants or replay them after authority changes. Unknown source authority is unavailable, not an empty list or a cached-content fallback.

### U08 — Correct the current comment without retargeting it (H / plausible)

An author with current permission may deliberately save corrected text/location on the same immutable target using an expected current revision, recording actual editor/time and a useful Edited cue. Do not overwrite concurrent edits or merge them invisibly. Text-only correction may retain its unchanged saved location without forcing a new preview, where current comment disclosure permits. A new/moved anchor needs current mapping; deliberate Remove location makes a general same-version comment. Do not silently drop an anchor when an older client or temporary preview cannot interpret it. A wrong-version post needs withdrawal plus a new authorized comment on the right target, not target mutation.

### U09 — Recover accidental withdrawal through qualified Restore (H / plausible)

Withdraw removes active text/marker from normal presentation and preserves only lawful indicators/history under the source schedule. It is not physical deletion or recall of what was read. Allow a deliberate current-authorized Restore of the **exact currently withdrawn revision and latest lawfully retained body/location**, creating a new attributed revision on the same target. A transient Undo may call that same command, never restore an old snapshot/grant. An unchanged anchor can return as Location unavailable without being dropped or forcing preview. A separately scoped operator may restrict/withdraw, restore when authorized, or add a separately attributed correction; never impersonate the author. Restoration cannot reconstruct disposed text, bypass redaction/restriction/source expiry, reset retention, revert to arbitrary history or resurrect a stale command. If no lawful restorable content remains, keep it withdrawn with safe actual feedback. No new Trash system, invented recovery window or routine second approval is selected.

### U10 — Comment retention and optional preview are separate (H / plausible)

A newer correction never inherits the old comment or geometry. A regenerated same-version representation may navigate the stored anchor only after compatible correspondence is proved against its actual qualified basis; equal dimensions/pages/digests alone are insufficient. Expired technical preview does not delete a lawful comment, force a download, grant forbidden old bytes or extend D32's deadline. Keep currently lawful text/context usable with Location unavailable. Current source restriction can bar comment disclosure independently of technical preview state. Retention preserves only actual required source history, not a perpetual body archive or history entitlement. Actual source rules, not a generic request unfinished/accepted predicate, govern staff comment continuity.

### U11 — Follow-up stays review context, not a new workflow (H / plausible)

Use a flat list and deliberate separately attributed same-version follow-up. Do not add a reply tree, Resolve/read/unread gate, @mention invitation, new email purpose or general inbox. Source review must declare its exact structural dependency on relevant comment revisions: an affected uncommitted prepared decision must revalidate changed review context, while an unrelated historical note must not invalidate all work. Do not use a semantic classifier to decide relevance. A later comment never undoes a committed Q21/Q23 decision, creates another Q22 completion condition, changes instructions or automatically requests replacement. Outward Q23/Q30 communication is a separately deliberate qualified action, not forwarding or changing visibility of internal prose.

### U12 — Protect every projection, not only the body (H / plausible)

Current source rules protect comment body, location/geometry, author, counts, history, snippets, links and source association. Render plain text safely; @names and URLs do not fetch, notify or authorize. Do not capture screenshots, extracted quotations or new body indexes. Q41 participants/external readers and Q44 ZIP recipients gain no staff-comment visibility or annotation export. Fence late responses and cached projections on source/assignment/Tenant changes. Logs, traces, replay tools and general diagnostics exclude private text/location/geometry/raw credential URLs; operator diagnostics are actually scoped, not a read-all shortcut. Preserve independently qualified existing carriers under their own contracts.

### U13 — Small bounded source work and capable operator recovery (M–H / workload-dependent)

Use native source, reader and shared UI seams with a compact optional typed location and one canonical comment/revision identity. Bounded source/version comment pages and needed page markers must not load every tenant comment, version, page or history, or perform one authorization/database call per marker. Stable pagination must distinguish incomplete coverage from none. No database persistence on keystroke/pointer move, CRDT, presence, broadcast-body subscription or new spatial/chat platform is necessary. Qualify finite body/request/history/marker/query/resource/retry/concurrency/retention bounds and fair overload behavior. Provide scoped correction, withdrawal/restore and location diagnosis without routine SQL/provider-console repair. Do not imply metadata/geometry work is free.

### U14 — Native qualification, safe rollout and accurate stage (H / plausible)

Adopt the ordinary source/comment purpose and narrow D32 authoring addition explicitly; reusing a post-comments screen or template renderer proves neither. Verify all native writers/readers, roles, RLS/PDP, service/operator/restore paths and storage/reader seams under actual current rules. Old clients must preserve or truthfully reject unsupported anchors/revision state. Do not backfill unqualified Party/post comments or legacy UI coordinates as verified evidence comments. Restrict unsafe marker operations during incidents while preserving independently lawful source/text work; that reduced operation is not final completion of A+B. One proposed **Document Review Comment** glossary term may clarify source-owned review context; use the owner's exact definition and keep all 26 current definitions unchanged until ratification. No current implementation, measured usability/cost result or Q46 decision is claimed.
