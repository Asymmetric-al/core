## Judgment

**Accept with required amendments.** Keep one optional finite selection within one ordinary request, with individual Accept equally available. One deliberate action may express several genuine current item decisions. It is not evidence inspection, automatic approval, a cross-request work queue or a new completion control.

The essential distinction is between **new decisions created by this action**, **independently existing exact acceptances**, and **actual source fulfillment**. The new decisions are all-or-none locally. Existing decisions retain their own truth and attribution. Fulfillment follows Q22's complete source predicate, possibly through its qualified durable recovery seam. A lost response cannot collapse these facts into “failed,” and a current Accepted badge cannot replace exact applicability proof.

The strongest B remains individual acceptance only: less grouped selection and conflict complexity, smaller accidental-action scope and no newly coordinated batch command. A is justified as optional command reduction after real review, not measured review quality, user preference, speed or zero-cost evidence.
