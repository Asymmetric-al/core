Where the original demand really must be replaced, use Q33/Q36 or independently qualified new issuance under their actual eligibility. This keeps one issued item basis stable and avoids a new same-item revision capability, but can fragment the request and its history. A mistaken unnecessary demand remains Q33. Q23 Request changes evaluates evidence against the actual current requirement; it is not an instruction-edit shortcut.
