## Why the actor policy remains open

Q02 establishes the principle that several typed uses can share bytes, but does not establish which actor may create a native new evidentiary use or whether the ordinary recipient must freshly affirm it. Q21 only reuses an existing **exact applicable acceptance for the same source/item/requirement/evidence/purpose**; equal bytes or another request/use cannot transfer approval. Q13 allows a **new authorized deliberate submission** to reuse qualified custody under its source contract, without defining a universal staff-on-behalf permission.

A native “Use existing” control therefore cannot just return a URL, attach an old file ID or copy an accepted badge. It needs current permission to discover/select/reuse the original source version, authority to admit a target use, target-required freshness/qualification, and truthful actor/receipt/review meaning. Deciding A or B would clarify the intended staff/participant journey while engineering qualifies the concrete source command and custody relationship.

This policy tells the embedded picker and File Manager what action they support and why a readable file may not qualify as evidence for the new target.

## Boundaries shared by both options

These keep the alternatives honest; they are not a completed adversarial review or extra founder questions.

1. Discovery, preview/download, reuse/link and target admission are distinct rights. The picker exposes only eligible permitted candidates and safe reasons; no restricted duplicate warning, title, thumbnail, count or unrelated Used in disclosure.
2. Bind a deliberate exact source version and typed target use. Neither filename equality nor current provider URL silently chooses a newer version. Preserve independent uses, old acceptance, retention and holds; removal of the new link is not byte deletion.
3. Target freshness, identity/attestation, consent and specialist purpose rules win. Source permission to read cannot be upgraded to permission to reuse, and staff rank/library ownership does not override required participant action.
   The target must currently permit this staff-originating new-evidence admission. This is not a way to change an accepted/frozen/closed item or revive expired source authority. Recipient access expiry alone is not relabeled a universal prohibition on independently authorized staff work; the actual source predicate governs.
4. Preserve truthful attribution. A staff-admitted existing file is not a new participant upload or confirmation. A participant confirmation is not proof of legal identity/authenticity or a source acceptance. Existing own-submission preview/history rights do not automatically expose a staff-added file or all its other uses.
5. Reuse bytes only where custody/integrity/current source permission qualify it; target source still performs its own exact review/acceptance. Prior acceptance in another use is not inherited. No need for a new upload merely to obtain a new source reference when reuse is lawful.
6. Keep original-source and new-target restrictions independently enforceable, with exact races/recovery. No private evidence becomes public/reusable email/CMS/AI/search corpus by a library action. Source disposals, withdrawals and existing holds remain authoritative.
7. The ordinary flow stays contextual: select eligible existing evidence, understand the target consequence, deliberately admit/propose it, receive a truthful result. No broad consent wizard, universal policy editor, arbitrary source chooser or new task platform.
