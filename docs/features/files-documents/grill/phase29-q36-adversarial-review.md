# Phase 29 Q36 — Add ordinary items to an eligible unfinished request

**Disposition: Accept with required amendments.** Conrad selected A and fully
ratified the complete amendment package, including the glossary refinement,
on2026-10-23, Asia/Bangkok. Q01–Q36 and23 definitions are ratified grooming
intent; one existing definition is refined, with no new term. The exact decision
and proof obligations remain intact. This is not native implementation, formal
owner/OpenSpec publication or activation evidence. Q37's answer is not inferred.

The useful product is small: authorized staff choose **Add item**, review the
new demand and its actual completion/access consequence, then publish it into
the same request. Earlier work remains intact. The recipient sees what was
added and what remains. Behind that action, the source must admit the new scope
explicitly; existing links, time periods and acceptance cannot silently change.
