## Recommendation and genuinely open choice

Use Q45 to choose **how authorized staff point to the location of an ordinary exact-version review comment**. Recommend **A — text comments with supported typed location references/navigation**. **B — additionally allow optional visual point/region markers on qualified static PDF/image views** is a credible stronger alternative, particularly for photographs, diagrams and dense scanned pages with several similar features.

Comments themselves are already required. Founder §10:213 requires intended version, supported page/location and business-purpose anchoring; A cannot mean version-only comments with no supported location association. Both options retain page/slide/sheet/cell/line references and navigation where the qualified reader supports them. A whole-version note need not invent a location. B adds spatial precision, not a new permission, source outcome, participant channel, compulsory marker or generic editor.

The recommendation is a scope judgment. A gives a coherent cross-format comment path using the existing reader's meaningful coordinates and avoids requiring a spatial-anchor lifecycle to complete ordinary feedback. Its real cost is the author's effort to describe an ambiguous region and the next reader's effort to find it. B reduces that ambiguity by showing the intended spot but adds geometry, zoom/orientation, rendering-generation, mobile/keyboard and stale-anchor qualification. There is no measured Asym frequency, error-rate, speed or cost evidence proving A superior; visual review could justify B. Neither option should be presented as universally best or as comments versus none.

## Shared constraints and B's exact extra obligation

1. **Exact source use/version remains visible.** A comment describes the intended immutable version and source purpose; candidate, accepted, superseded and unavailable retain source meaning. New bytes do not inherit old comments as statements about their current content or inherit approval.
2. **Location is optional assistance, not a review decision.** A general version note works without an invented position. A supported location makes the target easier to find; opening a comment, following a location or viewing the page proves no inspection, acceptance or resolution.
3. **Use actual representation coordinates.** Page/slide/sheet/cell/line meaning is derived from the supported source/profile. A DOCX reading-preview page is not automatically an original canonical page; PPTX numbering may have gaps; CSV delimiter/wrapping can change coordinates. Never guess a new location after profile/projection/source changes.
4. **Comments outlive technical previews only under their own source schedule.** D32's24-hour Ready and15-minute tentative deadlines govern technical copies, not comment retention. Keep source-owned exact comment/version provenance without retaining all preview bytes indefinitely. A new eligible rendition may support the same location only where actual compatible mapping is proved; otherwise show the permitted comment with honest location unavailability. Do not silently attach it to the same page number in changed content.
5. **B adds only qualified point/region metadata.** Bind a marker to the exact applicable static PDF/image representation and source version; zoom, rotation, orientation and layout changes must preserve the meaning or decline mapping. Keep the explanatory text and accessible equivalent; no text-selection/reanchoring engine, freehand drawing/redaction canvas, document editing, exported burn-in or every-format annotation is implied.
6. **Source confidentiality applies to text and coordinates.** Quotes, names, locations, page thumbnails and mere comment counts can disclose protected material. No sharing of all comments across equal bytes/source uses. Q05 participant restrictions and Q30's internal/outward separation survive excerpts and links. No new notification, mention fan-out, email default or read receipt follows.
7. **No automatic source outcome or retention extension.** Comments inform actual source work but do not change instructions, requirements, accepted evidence, request completion or participant access. Actual newly relevant information and stale-decision behavior must be qualified by the source without importing a blanket comment-resolution gate or inventing automatic review repetition.
8. **A failed reader is not a blanket comment ban.** Independently lawful source-context notes and inspection-failure information remain possible when their required authority is known; visual marker placement is unavailable when its own representation cannot be proved. No automatic download, external viewer, re-upload demand, cached private body or public-URL fallback.
9. **Stay inside the existing work surface.** Preserve comments/drafts, source task, reading position and focus where currently allowed. Source-owned staff comments are not a new chat app, global inbox or CRM-note thread. Editing/deletion/correction history and permitted actor operations need concrete owner qualification in the selected-answer review, not borrowed Q30 sent-message semantics.
10. **No new term yet.** This is a location interaction choice over required source-owned review comments. Do not add a domain identity or glossary term before its necessity is demonstrated; preserve the26 definitions.
