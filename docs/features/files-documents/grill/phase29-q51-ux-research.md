# Phase 29 Q51 — Directed staff attention from an exact review comment

2026-10-25, Asia/Bangkok. Independent primary research and UX recommendation. **Q51 is unselected.** Root records Q50's complete ratification; Q01–Q50 and all 30 glossary definitions remain the governing prior decisions. This note does not create an ADR, a stable message key, runtime behavior, notification default or formal publication.

## Recommended single question

**Should authorized staff be able to deliberately draw a specific eligible colleague's attention to an exact Document Review Comment, or should comments remain unaddressed while staff coordinate through existing qualified review/task work?**

| Option                                                  | Concrete experience                                                                                                                                                                                                                              | Best case                                                                                                                                                        | Cost                                                                                                                                                                                      |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **A — Directed comment attention (recommended)**        | Staff deliberately select a currently qualified colleague from an exact Q45 comment context. A source-owned informational cue uses the existing shared staff-attention presentation and returns to that exact comment/currently allowed context. | A particular person can discover relevant feedback without the author recreating it in another work item. The exact source, version and comment remain together. | Adds a new typed producer, recipient/currentness qualification and truthful attention lifecycle. Poor selection, repetition or too much preview content could create noise or disclosure. |
| **B — Unaddressed comments plus existing coordination** | Q45 comments remain available in their ordinary authorized source/work/reader context. Staff use an actual qualified existing review or task coordination route when another person needs attention.                                             | Fewer attention events and controls; sufficient when the existing reviewer work already brings the right person to the evidence.                                 | A targeted request for a colleague's attention needs a separate coordination act. The comment alone does not promise that person has noticed it.                                          |

Both preserve the required Q45 comment list, exact target, flat follow-ups, source review obligations and permission boundaries. B is not “remove comments,” manual recreation of evidence, compulsory task creation or an assumed daily-monitoring SLA. A is not automatic notification to all reviewers, a follower/subscription engine, a new inbox, assignment, deadline, read receipt or a Resolve requirement.

**Recommend A**, narrowly. Deliberate attention is useful when feedback has a specific intended colleague, while ordinary unaddressed comments remain the low-noise baseline. This is a product judgment informed by comparable behavior, not measured Asym usage. If routine source review already supplies adequate awareness, B is a credible simpler choice. Do not bundle either answer with an email default, group mentions, follower subscriptions, reminders, new access grants or a general collaboration platform.

Illustrative example, not an observed ministry workflow: Elena comments that a serial number on page 2 of Nora's submitted inventory is unclear. Ravi is a staff colleague with current permission to see that exact internal comment and source context. Under A, Elena can deliberately direct the comment to Ravi. Under B, she can use an existing qualified review/task coordination route to ask him to inspect the comment. Neither action makes Ravi the responsible reviewer, grants him original-file access, changes Nora's request or tells Nora that staff discussed it.

## Why this is open, and where it belongs

Founder §10 line 217 requires confidentiality for comments, annotations, mentions and notifications; mention must not grant access. That is not a blanket notification producer or channel/default decision. Q45's ratified ADR deliberately keeps `@name` text non-authorizing, selects a flat exact-version collection rather than a new inbox/task per comment, and states that no new notification follows from Q45. P17's generic assignment/@mention inventory defers stable keys until the actual producer meaning, owner, recipient and source fence are fixed. Q51 can resolve this exact ordinary-comment producer without turning every generic mention into a live event.

**Concrete proposed destination:** A should use that existing shared staff bell/center, not a separate document inbox. ## Proposed small journey under A

1. From a lawful exact comment/source context, the author or another source-qualified actor deliberately selects **Notify a colleague** or an equivalent optional addressed-comment action. A literal `@name`, copied text, opening a picker or hovering a suggestion is not the action.
2. The picker offers only people whose identity is disclosable to the actor and whose current exact staff context is eligible for this attention purpose. Selection does not grant access, reassign review or expose hidden eligibility details. Disambiguate same-name colleagues with permitted context; no raw email destination field, broad group broadcast or automatic first-candidate choice is required.
3. The deliberate final act admits the source-owned attention occurrence with the actual actor, exact comment/use/version and qualified destination. The UI must distinguish admitted, pending/unknown, failed and no-longer-eligible outcomes. It must not say the colleague read it or promise an unselected email.
4. The colleague sees the qualified informational cue in the existing staff surface under the right active tenant/context. Opening it returns to the actual current authorized comment and source context. A marker jump is offered only when the exact mapping remains qualified; expired preview material does not silently move the comment to newer bytes.
5. The colleague can continue ordinary allowed work or use the existing notification engagement controls. The cue imposes no new review completion, response, Resolve or read-receipt condition. The underlying comment remains under Q45; actual task/review ownership remains under its own source.

This is a proposed interaction shape for the selected-answer review, not a frozen decision between composer @mention and a saved-comment action. Either UI must express the same deliberate source act and exact target. Routine source comments without a selected colleague remain usable and create no new directed-attention occurrence.

## Limits, strongest objections and next-stage discipline

The strongest objection to A is that another attention stream may be redundant if existing assigned-review work already brings the right colleague to the comment. B avoids the extra event and preference/currentness lifecycle. That is why A should be deliberately addressed and optional, with no automatic subscription, owner-wide copy or requirement to read/resolve every comment. The strongest cost of B is additional coordination when a comment needs a particular colleague rather than the normal review route. Neither cost has been measured for Asym.

A mention is not a guarantee of attention, response, email delivery or source action. Vendor documentation does not establish a response SLA, daily staff visits, ministry usage, preferred notification volume, measured accessibility or unchanged operating bills. Source/P17/P12 integration and the exact first native presentation are product contracts to adopt and prove; native source, real roles, retry/privacy, intended-user and device tests remain separate evidence layers.

This question can be asked with one A/B decision. A selected-answer review must then close the typed producer, admission/result, eligibility, current usefulness, edit/withdrawal/retry behavior, bounded noise and existing presentation integration. It must not activate a generic mention key or treat the existing planned center as implementation evidence. Email defaults, follower subscriptions, automated reminders and source reassignment are not silently selected here.
