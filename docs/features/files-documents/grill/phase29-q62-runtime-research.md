## Result and practical recommendation

The ordinary source's use of approved purpose-specific retention is already mandatory. The inspected contracts do not select whether each new ordinary request automatically uses its currently applicable approved default or requires a deliberate policy selection/confirmation every time. That narrow interaction remains a fair question, provided both options consume actual qualified source policies and neither pretends to resolve Q61's remaining R-POL source-policy definitions.

**Recommend A: apply the actual approved source-purpose default and show the resulting binding in normal request review.** This suits repeat ordinary work without making staff repeatedly interpret records policy. An alternative is offered only when that source actually permits the current actor to choose it. A default is a supported source determination, not an arbitrary tenant duration or silent fallback. If no qualified default resolves, the product cannot invent one. An exact source may require a deliberate choice; A must respect that requirement.

**B remains meaningful: require a deliberate approved-policy choice or confirmation for every new request.** This makes case-specific intent explicit where the permitted choices genuinely differ, at the cost of another decision for routine work. With one lawful option, B is confirmation of that option, not a fabricated menu. Neither a click nor a default proves that the schedule itself is correct or that every required policy dimension has been supplied.

The scope should be assignment during new ordinary request preparation/issuance. Do not bundle policy administration, later issued-request reassignment, retroactive recalculation, legal schedule design, a generic records console or physical disposal into this question. The selected answer can subsequently resolve exact recovery and concurrency requirements. No Q62 answer is inferred here.
