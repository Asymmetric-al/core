## Recommended next question

**When a reader notices a problem with an organization resource, should they be able to report it directly from that resource to its authorized curator, or use the existing qualified Help/coordination route?**

Recommend **A — Add a small contextual Report a resource problem action**, for the already-admitted P28 missionary-reader publication scope. It should preserve the exact publication/version context and reach an actually authorized, capable curator-management route. The report is the reader's observation, not a review finding, change to the resource or permission to inspect something otherwise hidden. Keep the resource's ordinary reading and the curator's existing review/publish/withdraw commands independent.

**B — Use existing qualified Help/source coordination** is a serious simpler alternative. It avoids another source-report lifecycle and can handle questions, technical failure and sensitive personal circumstances in an already governed support conversation. Its cost is leaving resource context, describing what was seen and potential manual routing to the curator. Do not caricature B as “nothing happens”: it requires an actual capable route and honest safe instructions. Neither branch removes the required resource library or postpones its already-decided curation/review/withdrawal duties.

Illustration, not observed Asym research: Elena opens an organization travel-preparation resource and finds a link that no longer works. Under A, Report a resource problem identifies that permitted resource and the exact publication she saw, accepts a concise description and gives an acknowledged result. The authorized resource steward can assess it through existing management and deliberately correct the publication or conclude no resource change is needed. Under B, Elena raises the concern through the organization's qualified Help route, describing or supplying only a safe permitted reference; its actual support/source owner handles the issue. No private resource body, report or recipient identity is automatically copied into a different audience.
