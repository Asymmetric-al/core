## The correct ceiling and provenance

Use the **first lawfully admitted completed view for this same source request/intended recipient**, with its original completed-read action/member scope and Q05-permitted context, as the fixed baseline. For the new cohort, this baseline arose from the specific Q13/Q15 fresh unfinished admission whose valid authority supported actual normal fulfillment F. Retain that causal link and the actual completed end E.

The baseline is not the original unfinished request's wider set of requirements, the last fresh unfinished write scope, a union of all prior grants, or whichever files are currently present in a folder. Q13 already requires a separately declared completed-read scope; a participant could lawfully submit for a requirement without receiving every possible read action. Q16 cannot infer read access from writing.

At a later proposed read grant, intersect the baseline with current eligible own-submission members/actions and current purpose/recipient/representation restrictions, then review the permitted subset under Q08. A prior narrower individual read grant alone does not permanently shrink the baseline; a genuine binding source restriction remains binding. A source repair of a valid projection can restore the originally admitted facts, but it cannot enlarge the baseline or replace the original bytes.

“Admitted completed view” means durable source authority, not proof that a browser rendered it or the person downloaded a file. Never-used access can still have been lawfully admitted. Lack of visit/telemetry is not lack of authority; a screenshot or old success log is not proof that the authority existed. A temporarily unavailable preview or representation is not itself a grant failure, and qualified repair of the same already-authorized original remains separate from adding another file/member.

Do not require at least one historical successful file open merely to enter this cohort. Conversely, no-view cases must not acquire a completed admission solely because the business source shows completed. Required historical policy, recipient/scope eligibility and causal grant-at-F must be proved; current storage possession is insufficient.

## Minimal implementation consequence if selected later

Extend the existing intended Q08 eligibility predicate to one additional proven provenance route. Keep the same current issuer administration, source purpose/recipient, baseline read ceiling, meaningful staff action, current participant proof and private serving. Model the baseline's provenance exactly enough to distinguish original ordinary completion from a lawful continuation completion, but do not prescribe a new aggregate, public terminology, separate renewal queue or another interface.

One source-owned read-admission fact and its original ceiling can support both cohorts under the same reviewed contract; the implementation still needs real-role/currentness/causal/restore qualification. Any migration of old records must prove historic admission rather than reconstruct it from task dates, filenames, access logs or current permissions. An unknown original scope fails closed for this grant while preserving unrelated legitimate source work.

The staff UI can retain the existing **Grant read access** action on the same completed request. The internal provenance should explain eligibility to appropriately authorized staff without forcing a recipient to understand “ordinary versus continuation” or exposing additional private files. In both options the source stays completed and read-only.
