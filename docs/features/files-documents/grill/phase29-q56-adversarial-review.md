## Decision, necessity and strongest alternatives

Keep normal upload short. Offer a small optional composer when a person wants several page photos to become one ordered PDF in the same request. Add/reorder/rotate/replace/remove, then one deliberate submission is enough. One-page PDFs are valid. Ordinary photos and prepared PDFs remain equally valid where the source accepts them.

Direct intake alone is the strongest simpler alternative: fewer transformations and lower processing/retention cost, but users sometimes need another tool to produce an ordered PDF. That inconvenience is plausible, not measured Asym field research. Conrad has chosen the added convenience. The permanent answer is a bounded source-owned assembly, rather than a scanner application, new editor platform or policy matrix. Browser-only generation is attractive for server cost, but does not by itself prove the submitted PDF corresponds to retained original inputs; the selected truthful lineage requires qualified trusted production from exact inputs. A full scanner/OCR/crop/filter suite adds costs and meaning not requested. No universal nonprofit consensus, usage frequency, cost neutrality or task-time benefit is claimed.

The important new fact is the **whole contribution**: selected original photos plus exact ordered recipe plus a separately identified PDF. Preparation does not mutate the source or fence prior evidence. A complete qualified unit is admitted atomically. This keeps the UX short while making correction, withdrawal, review, downloads and cleanup coherent.

## Ratified glossary amendments

Ratified new term:

**Document Assembly**:
A source-owned contribution that presents an ordered set of selected image originals as one assembled document. It preserves the identity of its originals and assembled output and is distinct from a Document Request Item, an original file, a preview and item acceptance.
_Avoid_: original file, preview, request item, accepted evidence, merged history

Ratified **Submission Confirmation** replacement:
The source's record that an exact file version or Document Assembly was durably received for a Private Document Request. It does not mean the received material is safe to preview or that the requested business evidence has been accepted.
Its existing Avoid list remains unchanged.

Ratified **Staff-supplied Document Evidence** replacement:
An exact file version or Document Assembly deliberately supplied by authorized staff for a Document Request Item, with attribution to that staff act. It is distinct from a participant's submission or affirmation, item acceptance and permission for other uses.
Its existing Avoid list remains unchanged.

Submitted Original and Document Review Comment need no change: the original remains exact received bytes, and a comment can already target the exact use/file version. Assembled PDF is a clear output label, not a second new glossary term. The canonical glossary now contains 32 ratified terms: Document Assembly is added, Submission Confirmation and Staff-supplied Document Evidence receive exactly the adopted refinements, and all 29 other definitions and both existing Avoid lists are preserved.
