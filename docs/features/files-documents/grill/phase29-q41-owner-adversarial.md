## Proposed glossary addition

**Private Document Share**:
A source-authorized, finite permission for a named recipient to read specified private document material for a stated purpose through explicitly permitted actions. It is distinct from an invitation, recipient confirmation, a collection request, retention and permission to alter or reshare the material.
_Avoid_: anyone link, file ownership, folder membership, request-only access, proof of reading

This distinguishes a source grant from existing collection-specific Request-only Access and the transport entry. It creates no table, new role or generic permission platform. Preserve all25 existing definitions; the26th term is proposed only and must not be added canonically before full ratification.
