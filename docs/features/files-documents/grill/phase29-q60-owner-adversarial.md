## Outcome and principal findings

Correct the exact staff decision, not the file or historical fact. An eligible unfinished correction records that an exact earlier item acceptance was made in error, ends its use as currently applicable acceptance, and returns the actual item to current staff review. It does not itself request new bytes, revive old guidance, renew access or send email. If the request is already fulfilled or otherwise terminal, record a source-owned acceptance-error/current-reliance disposition while preserving the original acceptance, F, terminal state and access history. Real further work uses an independently reviewed new corrective request or the actual specialist remedy.

The correction itself must be recoverable. While ordinary review remains eligible, fresh Q21 review may accept retained evidence on the new actual basis; the old acceptance is not replayed as current. For a mistaken terminal error finding, a new source-qualified reassessment may remove only that finding's own blocker on actual evidence, while every independent requirement, safety, purpose and downstream restriction remains. Original acceptance/error/F actors and times survive. This is an explicit narrow Q60 post-closure reliance remedy, not a general reopened review, historical record editor or approval rollback.

For genuinely needed same-person corrective collection after closed work, provide one resumable source preparation and one ever-issued result per admitted error-remedy intent. Actual identity, current legitimate need, exact scope, Q25 original readiness, Q01 proof and original access terms qualify anew. This new same-recipient remedial lane does not borrow Q49's different-person authority. Preserve unaffected sufficient facts and allow only independently qualified evidence reuse; staff error must not force fabricated uploads. The initial corrective-request cohort has no automatic Q48 plan or Start/Resume workaround, preventing a request recreation from resetting automatic limits or escaping a recipient stop. Lawful manual reminders and original-issuance notices retain their own current purposes. Same-request correction preserves all existing Q48 counts/settings/stops.

The strongest B was separate corrective work for every substantive acceptance error, including errors discovered while useful work remains unfinished. It avoids a same-request transition but can replace a workable request, fragment review and create new access/preparation burden. A is preferable for continuity, with terminal history preserved and explicit remedies. The observed mistake rate and user-time benefit are unmeasured; vendor reversal controls are evidence of a possible interaction, not authority for a blind toggle.

## Proposed vocabulary, pending ratification only

**Document Request Item Acceptance Correction:** The requesting source's attributed record that a specified earlier Document Request Item Acceptance was made in error, together with its current source consequences. It preserves the original decision and is distinct from Submission Correction, Request changes, deletion and request reopening.

_Avoid_: unapproved file, Undo acceptance, edited receipt, deleted decision, reopened request, new access grant

This term distinguishes a staff-decision correction from the already-defined Submission Correction of supplied evidence. The record is a source judgment, not proof of legal authenticity or an immutable assertion that later evidence can never correct. Its later finding-reassessment remains separately attributed. No Correction Case/Session/Graph term is needed. If fully ratified, this would be one33rd Files term; this note changes no glossary.
