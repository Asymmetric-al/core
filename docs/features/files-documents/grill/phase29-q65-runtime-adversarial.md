## Outcome and early material findings

**Accept with required amendments.** Add a narrow source-owned ongoing reference to exact qualified accepted evidence, through a deliberate authorized act. Keep the original collection record and immutable provenance. Provide actual End and Replace/recovery behavior, current target-purpose reading and exact original-operation recovery. Do not create a contract registry, signature authority, automatic latest-version feed or new permission engine.

The most important findings are:

1. **Name the new source authority explicitly.** GEN-05 is coordination and P9's organization/Files socket is context, not an implemented reference source. The narrow ordinary partner-document-reference source must own the use's admission, current state, replacement/end and history. P9 retains organization/relationship truth, P29 retains custody and P12 retains permission. Actual native producer binding remains a gate; an undefined “partner source” cannot be the only repair plan.
2. **Target authority differs from original-request browsing.** After valid admission, eligible reference readers use the current target purpose plus applicable original-source restrictions. They must not be forced to browse the original request or inherit its private transcript, staff notes or participant windows. Nor does adoption remove source classification, origin restrictions or current reliance errors.
3. **Accepted evidence may be a complete unit, not one asset.** Q21 acceptance can cover several contributions/files; Q56 assembly has necessary input/recipe/output lineage. Preserve the actual source-qualified accepted unit and its complete relevant acceptance basis. Do not invent a per-file accepted flag or flatten an indivisible evidence set.
4. **No universal cardinality or permanent byte ban.** Suppress equivalent active uses only under actual target/purpose/qualified need/exact-basis semantics. Distinct legitimate references can coexist. A new lawful admission after End is not forever forbidden because the bytes match; an old retry must never revive the ended use.
5. **Reference/custody admission is one coherent fact.** No visible favorable reference before all required source-use/copy protection is durable. Admission, Replace, End, restrictions, holds, promotion and disposal must share proved ordering. A metadata FK alone cannot stop an already possible physical delete.
6. **Correction changes current reliance, not historical truth.** Q60 errors/finding corrections and other source restrictions must reach affected current reference use. Do not leave a misleading favorable reference while waiting for a background job, rewrite old F/acceptance, universally revoke lawful repair reads or automatically select different bytes.

These are prospective design/reuse risks, not assertions of a deployed Q65 defect. No qualified partner-reference implementation or effective hosted policy was established by this review.

## Minimal permanent behavior to resolve

The first offered cohort should be deliberately selected, currently source-qualified accepted evidence from the reference collection—not all files discovered on a partner record. A request being fulfilled, unfinished or canceled is neither a universal grant nor a universal prohibition: actual source reuse eligibility and current applicability of the selected accepted unit govern. Historical acceptance alone is insufficient, and adding the reference does not reopen the original request.

Use a small source-owned relationship with exact immutable target evidence/basis, current reference revision/effect identity, real target partner/purpose, admitted policy and history. This describes invariants, not mandatory table/column names. Whole evidence-set membership and required assembly lineage must remain recoverable. The source may expose the unit through a single readable output while preserving its underlying complete lineage; it need not grant every reader raw assembly inputs or all original submission history.

Suggested ordinary actions are **Use for partner reference**, **Replace reference** and **End reference** within actual source context. Admission is not automatic when staff clicks Accept or when a workflow finishes. Replace is a deliberate current adoption, never follow-latest; End only ends this use. If End was mistaken, support a fresh current admission of still-qualified retained evidence linked to the prior end, not old-grant Restore or compulsory reupload. Exact visible labels remain subject to root/UX reconciliation.

Current temporary permission/technical/reliance blocks are separate from an ended use. A source-qualified repair may restore lawful availability under unchanged terms/current checks when the use itself never ended; old blocked data is not automatically reclassified as current. An actual End remains ended. This avoids both perpetual accidental revocation and unsafe replay resurrection.
