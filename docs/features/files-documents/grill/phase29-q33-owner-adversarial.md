## Main conclusion

Keep A as one bounded source decision that stops an unnecessary document demand. It is not evidence acceptance, file deletion, terminal evidence rejection or whole-request cancellation. The important amendments are the exact source authority, nonvacuous Q22 completion, honest preservation of receipts and independent obligations, and a real correction path for staff mistakes.

Three corrections are decisive:

1. **The item remains a known source fact.** No longer required ends this exact obligation under current authority. It does not make the row disappear, declare the evidence acceptable, erase a former Request changes decision, or excuse other genuine source/safety duties. Obsolete work belonging only to the removed demand must also cease; otherwise an invisible review concern can leave a request stuck forever.
2. **Removing the last item does not make an empty query authoritative.** Q22 evaluates the complete eligible current source predicate, including exact not-required decisions and genuine remaining obligations. When that predicate is true, it fulfills without another routine Complete click. A canceled, withdrawn, undefined or no-longer-legitimate whole request cannot be made successfully fulfilled by repeatedly removing items.
3. **Correction is a new authorized act, not reversal of history.** While the same request remains eligible and unfinished, a deliberate source correction can supersede the exact mistaken removal on its original item/requirement lineage. It re-evaluates current evidence and permissions rather than restoring an old snapshot. If fulfillment already won, the old request and access clocks remain closed. A concrete terminal remedy must use an independently authorized new ordinary request or another already-qualified effective source remedy; it cannot be an invented generic Reissue or a contact label with no actor able to act. The remedy below is an explicit proposed review amendment, not an assertion of current implementation or inherited authority.
