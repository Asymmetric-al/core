## Recommendation and the actual remaining choice

Recommend **A — allow optional private Save for later for currently qualified organization-resource readers**, alongside the existing search and navigation. **B — retain qualified resource search, categories and navigation without an in-product saved-resource list** is a complete and credible simpler alternative. The useful difference is whether a reader may deliberately remember particular publications for a later visit without reconstructing a query or remembering a title. Neither option changes which resources must exist, who can read them, or what publication means.

A should save a private reference to the exact P28 source publication identity/lineage. Reopening resolves that publication's current permitted source state. It does not save a file copy, frozen edition, historical byte entitlement, offline content or a grant. The same publication's source-qualified replacement/current head can remain the reference's destination. A genuinely separate publication or Q58 audience-specific edition is a different target even when its title or underlying bytes match. An authorized successor suggestion may explain where useful replacement guidance exists; it must not silently transfer the person's saved intent to another publication.

I recommend A because the required library already serves repeatable operational guidance and now has qualified staff and missionary reader cohorts; a small personal return list is a coherent convenience. This is product judgment, not measured Asym demand. No return-frequency study, task-time saving or production usage measurement was found. B avoids durable personal relationship state, unavailable-reference handling and associated maintenance, and remains attractive for a small or infrequently revisited collection. A must stay a modest Save/Remove/return feature rather than become a general collections, subscription, acknowledgment or recommendation platform.
