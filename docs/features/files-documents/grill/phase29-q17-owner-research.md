## Make B complete and fair without overdesigning it

B must include a finite unused opportunity established at the new source issuance. A finite entry boundary plus a finite reading interval yields a finite maximum possible lifetime even before exact entry is known. All numeric values and supported time interpretation remain to be selected and qualified before activation.

The strongest B gives the chosen full reading interval after a timely qualified entry, **clipped by genuine independent limits**. Its entry-only boundary is not secretly an overall ceiling that truncates a late entrant's entire reading period. Conversely, an actual hard purpose/overall end is not relabelled entry-only. This stage distinction is part of the offered B model and must be stated, not buried in implementation.

“First qualified entry” must mean the source-confirmed first deliberate entry by this intended recipient into this same fresh admission under current Q01 proof/authority. It is not an email open, scanner GET/HEAD, page prefetch, analytics event, first file successfully rendered, file download or an unrelated account sign-in. Existing protected-action/identity owners must supply the qualified handoff. Do not add a ceremonial Start my timer button or a second login merely to create that event. An already-confirmed compatible recipient may enter through the existing qualified path; every later device/visit/proof repair preserves the first end.

Entry at or after the applicable exclusive boundary is too late. Reconcile a real timely durable entry from original evidence when observed later; a click that never became a qualified source effect does not reserve time. Expired/unknown authority is not repaired by moving the start to the next visit. A known source-approved conditional admission exists under the issued terms; do not silently substitute a perpetual staff approval that becomes an entirely new grant whenever someone eventually arrives.

Unlike Q14's former first-entry alternative, this completed-read lane has no pending source-fulfillment event to enter another stage before recipient entry. Independent preview preparation/audit/custody uses its own source authority and does not start or extend the recipient reading period. This makes the explanation narrower; it does not remove the need for current source/issuer/recipient and entry/expiry/revocation race qualification if B is chosen.

## UX consequence to put plainly in the founder question

For A: “Your read access ends [date/time/zone]” after confirmed issuance; late arrival has only the actual remaining time. Never promise a full new interval on arrival. Before issuance, show the standard rule and controlling limits, with any estimated end clearly labelled until admitted.

For B: before first entry, authorized staff/recipient context explains the finite enter-by boundary and the subsequent reading rule; after qualified entry, show the actual read end. An unqualified public link must remain neutral/non-enumerating and cannot expose private request facts merely to show a timer. Failed preview, a partial download or session renewal never restarts the period.

Use Q08's one meaningful **Grant read access** action and existing completed view. The choice changes the opportunity window, not whether recipients need a new account, how many approvals staff perform, whether files can be edited or whether an email is sent. No universal readiness assumption or delivery guarantee is justified.
