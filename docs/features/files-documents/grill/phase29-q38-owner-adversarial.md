## Minimal lifecycle and operational controls

- Source facts and immutable use/version identity remain authoritative; the finder is a query/projection, not another domain owner.
- Admitted metadata may be searchable independently of byte preview/readiness only where that owner permits; unsafe bytes must not be fetched merely to search.
- Current restrictions precede stale result contribution and later reads. Cleanup, source retention and independently valid uses remain separate.
