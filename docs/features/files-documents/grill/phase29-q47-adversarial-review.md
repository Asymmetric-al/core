## Complete user journeys and small UI

The routine path stays inside the request: identify the exact received contribution, read a short consequence and choose the final Withdraw action or Cancel. Show “Withdrawn from review” persistently where source-visible. Offer “Offer this file again” when current retained-version resupply qualifies; its final action creates a new review admission. A disappearing Undo toast is neither the sole recovery route nor a promise to reverse history. Exact copy is localized and tested, not frozen as a new component system.

The tenant control should clearly say **Recipient self-service withdrawal**. Off affects new participant withdrawals, not all file changes or staff assistance, and a known source default needs no redundant row or extra administrator task. Staff-assisted withdrawal uses the same target/consequence clarity with real staff attribution and legitimate source basis; source-required assistance context need not become a narrative essay. Staff who merely administer settings, inspect files or review do not silently acquire the new power.

Participants without a Party/full account use their actual qualified request context. A withdrawn historical row offers only permitted identification and outcome; no thumbnail, preview/download, search snippet or ZIP shortcut creates an archive. Actual independent byte/source rights still govern. If metadata cannot distinguish same-name contributions, route to capable source help rather than revealing more or confirming blindly. A donor, public visitor or specialist finance user receives no new generic rights by association.

Staff retain exact reading context and notes while the current basis changes; no silent file swap. Relevant acceptance must revalidate current basis. Existing independent privacy/incident work can restrict or dispose material through its own source authority; withdrawal is not a claim of unread, deleted or recalled content. The new actor/time/history and current-work labels must be understandable after refresh and on a weak connection.
