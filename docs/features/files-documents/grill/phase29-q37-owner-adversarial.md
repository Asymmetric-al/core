## Owner conclusion and the actual product

Keep one deliberate **Update instructions** action for currently source-authorized staff, on the same outstanding, not-currently-accepted ordinary Document Request Item in an eligible unfinished request. It may correct what the same document need is asked to contain or describe. Preserve the submitted-under instructions and each evidence/review act, publish a prospective successor, and make the actual next work understandable. Do not turn the action into a different document requirement, new recipient/purpose, requiredness override, accepted-item rewrite, schema designer or broad mutable request editor.

The important distinction is three separate facts: **the instructions under which evidence was received; the current source instruction revision; and the exact basis of each later review**.
