## Recommended next decision

**May authorized staff upload a newly received local file directly into an eligible ordinary Document Request Item as staff-supplied evidence, or must new files enter through the recipient while staff retain Q28's existing-file reuse?**

Recommend **A — allow source-authorized staff upload with truthful staff attribution**. The useful distinction is who can supply bytes that are new to qualified Asym custody. This is not another approval or notification question. Q28 already permits staff to select eligible versions held in qualified custody, but it does not silently grant a local-file upload source lane.

Illustration, not an observed ministry workflow: Nora receives Elena's equipment inventory outside Asym and has a lawful local copy. Elena's ordinary request item still needs it. With A, Nora opens that exact item, chooses the file and deliberately uploads it as evidence supplied by Nora. Transfer, source receipt, Checking, inspection and acceptance remain separate. With B, Elena submits the new file through her own qualified request path; Nora may still choose an independently eligible file that is already held in Asym under Q28.

“New” means new to qualified Asym custody in this journey. It does not mean recently authored, current, authentic, signed, consented or substantively sufficient.
