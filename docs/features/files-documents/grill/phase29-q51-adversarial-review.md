Integrated Post+Notify is fewer clicks in one case but entangles two otherwise independent acts and their recovery. ## Source ownership and lifecycle invariants

The ordinary source owns the exact comment eligibility, attention act, semantic once-only boundary and current purpose. Native identity/P12 owns actual staff identity and current powers. P6 owns complete compilation, released plan/member and communication facts. P17 owns recipient availability/presentation and engagement. Custody owns original/preview bytes. None owns another's truth by display or foreign-key proximity. One admitted act has one stable intended principal and one original concrete context, one source revision, one complete local result and immutable attribution. The read model cannot grant permission, move targets or resolve source work.

## Small UI and complete user journeys

Use a visible or consistently discoverable saved-comment action, including keyboard/touch, not a hover-only icon. The small selector shows **Notify a colleague**, **Colleague**, concise **Adds a notification in Asym. Access does not change**, and **Notify / Cancel**. Display safe selected-person/context disambiguation. Keep the comment in context; no need to open a file or enter another message. When optional controls are Off, show an appropriate short explanation only to an actor allowed to know that setting; otherwise use a neutral unavailable result.

During the command use **Notifying…**. A proved atomic result permits **Notification added**; it does not permit **Ravi read it**. A same-business duplicate can say **Already requested for this version of the comment**. A lost response uses **We couldn’t confirm the result. Check status** with original-operation recovery. A stale revision uses **This comment changed. Review it before notifying someone**. Known no-effect and unknown completion remain distinct. No technical transaction, Party, epoch or hash terminology enters ordinary UI copy. Essential result/action remains inline and accessibly announced; a toast is supplementary.

The recipient sees a minimal permitted source cue and **View comment** in All. It never appears as required source work. A changed comment says **This comment changed since the notification** while showing only current authorized same-comment context. Unavailable material says **This comment is no longer available** only when that fact is permitted; broader denial uses a neutral safe message. Normal read/archive is available under P17's policy. No evidence acceptance, participant response or private history is inferred.
