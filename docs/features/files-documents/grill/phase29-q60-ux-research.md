## The single practical question and the strongest alternatives

**Illustrative situation, not an observed Asym workflow:** Elena requests an equipment inventory and a packing list from Nora. Elena accidentally accepts an outdated inventory while the packing list is still outstanding. The inventory's actual submission and Elena's original decision must remain attributable. The team needs to stop treating that decision as sufficient and get the right work reviewed.

Contrast the same error when the inventory was the last requirement and the source has already recorded fulfillment. Reversing a green badge must not secretly reopen the completed request or renew Nora's expired access. That second situation needs separately authorized corrective work under both options.

**Proposed question:** When staff discover a mistaken acceptance, should they be able to correct it inside the same eligible unfinished request, or always move the corrective work into a separate request/work record?

| **A — Correct it in the same request while the request is still eligible and unfinished (recommended)** | Authorized staff deliberately correct the exact acceptance; the source records the correction/current applicability, preserves the original actor/time and returns only the affected item to actual review/required work. B is not a universal ban on recording corrected truth in the original record. That truth must change under either choice. Its distinguishing choice is where subsequent review/collection work lives. B's concrete same-recipient handoff would be an explicit Q60 source adoption; neither Q49 nor templates grant it automatically.
