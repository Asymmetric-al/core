## Exact proposed clauses

### C01 — Cohort, namespace and actual owner

Provide one ordinary-source staff filing namespace per exact Tenant and environment for evidence durably admitted by the ordinary Private Document Request source. Each eligible file contribution/use for one request/item has one home folder or the null/derived Unfiled state. This is not a home for the whole multi-file item, provider object, digest, filename, every version or all independent uses of equal bytes. The source supplies the exact typed stable reference and governs eligible metadata/organization states; P29 supplies shared custody and experience. Preserve tighter actual source/field restrictions within the namespace. No new general drive, universal Logical Document, folder ACL, cross-tenant root or specialized-owner migration follows.

### C02 — Placement and legitimate source lifecycle

New independent participant contributions and Q28 target uses start Unfiled without labels or inferred business placement. A receipt needs no filing/label action to be usable through its authorized source/list. Same-use metadata, instructions, review or lifecycle changes do not manufacture a new filing identity or automatically move/remove it. Checking, rejection, historical, fulfilled, canceled or retained states do not themselves settle staff organization rights: preserve or deny the actual operation under current source authority. Do not require acceptance, preview readiness, active participant access or Q41 sharing eligibility merely to manage permitted metadata. Source disposition retains its own rules; retained membership remains real for folder integrity even when absent from an ordinary current list.

### C03 — Exact successor home continuity, without semantic copying

At actual admission of a source-declared Q03 correction, or an explicitly qualified Q28 withdrawal/add replacement, permit a one-time copy of the exact predecessor's current home only when the source proves the same Tenant/environment/request/item lineage and current compatible destination/organization basis. The source's narrow maintenance authority performs this; the participant does not acquire folder powers. New independent additions/reuse, matching bytes/names and ambiguous multi-file relationships do not qualify. The new use receives **no copied labels**, review result, acceptance, retention override, share, read grant or historical access. Freeze the copied home and source basis at the source admission order; preserve the predecessor's own organization and history. Later moves, retries, background work and restoration cannot propagate or recompute the latest home. If that optional copy cannot be proved or conflicts, record Unfiled for the new use without failing an otherwise lawful evidence receipt. Unknown or invalid source admission authority, custody or required evidence conditions still block Q03/Q28 admission; they are not optional filing failures. Show the actual resulting staff filing state and permit normal later Move; do not promise deferred automatic backfill. The Q03/Q28 evidence/current-review lineage remains unchanged.

### C04 — Current organization and metadata authority

Every folder/label/view read and organization mutation uses current source/P12 authority from trusted tenant/context/actor facts. Permission to read bytes does not imply permission to file, and filing permission does not grant bytes. Folder and label metadata have their own actual source classification and disclosure policy; do not expose a private target title, association, breadcrumb, count, option or timing distinction merely because a container is visible. Apply current restrictions before discovery, contribution, ordering, pagination, serialization and saved-result recovery. An external participant or Q41 reader receives no staff tree or other-use discovery. Authorized source stewardship must support recovery without ambient administrator or service-role bypass.

### C05 — Labels and saved views stay organization

Allow zero or several bounded source-permitted labels on an entry, with duplicate assignments prevented. Labels are authored organization metadata, not acceptance, safety, hold, request state, consent or permission; a label named Reviewed does not establish review. Preserve source classification and Q38's body-exclusion boundary, without introducing a semantic classifier or taxonomy engine. A saved view is a bounded typed query definition over approved fields, filters, ordering and display preferences, re-evaluated against current authority each time, never a captured membership/grant. Reuse the actual generalized private named-view seam for actor-owned ordinary views and qualified source/system views. Do not silently activate reserved team/everyone visibility or pretend a shared URL grants its viewer the same results. A missing/retired field, label, folder or incompatible definition must have a truthful repair state; never drop a filter and widen results. Founder-required shared-view outcomes remain on the product coverage map for explicit audience qualification, not deleted or asserted implemented by this increment.

### C06 — Non-destructive folder lifecycle

Folders have stable opaque identity, a display name and optional same-namespace parent. Enforce same-scope parentage/placement, no self-parent/cycles, declared finite depth/name/operation bounds and a documented Unicode/collision rule. Preserve display text and distinguish duplicate file names by source context; do not rename source evidence to resolve folder ambiguity. Provide deliberate create/rename/reparent and Move to folder/Unfiled. **Remove folder succeeds only when authoritative organization state proves it has no directly filed entries and no child folders.** Staff first use existing bounded Move operations for contents/children. Do not recursively delete/rehome, infer empty from filtered current rows or disclose concealed membership counts to explain denial. A current qualified source operator must have a safe way to resolve otherwise hidden/retained structure. Removed/recreated names do not revive the old folder identity. D18/D27 retain their different existing removal rules.

### C07 — Query and source-navigation integrity

Keep All permitted entries, Unfiled, exact folder scope, labels and source navigation understandable; a saved view or search result is not another folder placement. Preserve Q38 approved metadata/source-context matching and independent action authorization. Zero matches is a completed query fact only when required evaluation completed; unavailable/partial authority or query work is not zero. Definite policy exclusions remain undisclosed, without per-hidden-item explanations. Source facts, not a newest-byte pointer or browser corpus, determine visible version/currentness. Do not let ancestor membership, a renamed label, stale projection or restore reintroduce a restricted association.

### C08 — One coherent mutation and exact recovery

Every organization command derives current scope/actor, validates expected placement/structure and commits its intended changes with required restricted business audit coherently. Use permanent semantic operation identity and exact intent binding. Reconcile a matching committed result before new-command eligibility, under current result disclosure; a different intent with the same key conflicts. Retries must not replay an earlier move over a later deliberate move or recompute a correction's inherited location. Source mutation, folder deletion, label edit, policy change and correction admission have defined ordering; stale attempts preserve the prior coherent result or report a supported conflict. No provider-byte move or second cross-provider transaction is needed for folder metadata.

### C09 — Finite bulk and unchanged source meaning

Bind an explicit finite list of exact entry identities/expected state for bulk Move; selected visible rows are not all matching records. One submitted bounded ordinary bulk Move is all-or-none: recheck every current target/destination and relevant expected state, and coherently commit the exact batch plus required history or none of it. A single stale, unauthorized or invalid member cannot produce hidden partial movement. Reject an over-limit batch or explicitly split it before submission; do not silently chunk one promised atomic command. Reconcile the original batch without multiplying effects, retargeting newly visible rows or silently rewriting later choices. Independent later batches and separately qualified remote/export operations retain their own truthful outcome contracts; this local Move rule does not make them atomic. Organization commands do not submit evidence, accept/reject, change requirements, publish, reshare, extend access, change retention or emit a new Q27/Q40 source event. Their own appropriate audit remains required.

### C10 — Native integrity and all writers

Represent exact tenant/environment/source/use references and folder ancestry with appropriate typed same-scope constraints, null/uniqueness rules, indexes and deletion restrictions. Persist the at-most-one-home invariant; labels use distinct bounded associations, not extra folder placements. Derive authoritative attribution server-side and prevent allowed updates from reparenting tenant/source/use or granting future versions. Verify actual table grants, RLS SELECT/INSERT/UPDATE/DELETE and USING/WITH CHECK, mixed policies, UPSERT, views/RPCs/functions, triggers and service/job paths. P12's current capability/field floor remains distinct from coarse RLS. Folder/label/view deletion cannot cascade into bytes, source evidence, acceptance, obligations or active Q41 grants.

### C11 — Accessible routine work and capable correction

Provide a labeled Move action and searchable destination picker with Unfiled, actual source context, clear success/conflict/unavailable states and preserved valid selection; dragging is optional and invokes the same command. No routine confirmation modal, forced preview, repeated upload or permission ceremony is needed for a normal reversible single move. A mistaken move is corrected by another current-authorized Move, not a stale snapshot Undo. Preserve keyboard/non-drag pointer, touch, focus, screen-reader/status, zoom/reflow, long/RTL/Unicode names and low-bandwidth retry behavior. Show safe current location and source version context without implying a folder is ownership. No selected control changes state before deliberate submission.

### C12 — Bounded activation and stewardship

Qualify finite folder/depth/label/view/query/page/bulk/corpus/concurrency/recovery budgets and actual composed workload before activation; do not borrow P23's five levels or workload numbers as ordinary authority or claim zero cost. Reuse existing source/query/UI mechanisms without a new rule builder, sync service or generic organization platform. Backfill only exact known source mappings; preserve eligible legacy metadata and bytes, and use Unfiled where no lawful placement is established rather than guessing from provider paths. Fence incompatible writers and source restrictions before derived serving. Rollback can disable affected organization commands while preserving evidence and lawful source access. Recovery/restore preserves semantic operation history and current denial fences. Separate restricted business audit, access evidence and redacted technical metrics. Record actual source/use/actor/operation/placement outcomes without content, private labels or hidden associations in ordinary logs. Canonical owner/OpenSpec publication and native proofs are required at their separately authorized stages.
