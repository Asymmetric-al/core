## Minimum practical consequences if A is selected

1. **One deliberate source act.** Edit the actual requested-by target for the actual eligible outstanding submission scope, showing the current value and proposed replacement. Current P12/source administrative capability and restrictions govern; being a task assignee, knowing a request ID, or having byte-read access alone is insufficient. A source-authorized date correction need not require opening every submitted file.
2. **Prospective terms with historical truth.** Preserve the old value, applicable scope/interpretation, actor and trusted effective source event. Earlier receipts retain their exact applicable timing evidence or unknown state. Moving a target later may change the current outstanding-work cue prospectively; it cannot turn an earlier recorded late receipt into timely. Moving it earlier cannot retroactively label an earlier receipt late. Correcting an erroneous historical fact remains a distinct governed correction.
3. **Use the real target representation.** Show the source-resolved date/instant and any relevant timezone/interpretation, not a silent browser-local conversion. An optional clear is permitted only under existing source rules; it means no current requested-by target, not an invented infinite deadline or loss of old evidence. Missing target evidence stays unknown where required; it is not zero, midnight, timeless permission or automatically a stop to otherwise-authorized intake.
4. **Keep time authorities separate.** Display the actual access window/hard intake limit when relevant. Moving requested-by beyond an access end cannot promise the participant can submit then. An expired/revoked admission is not revived by a target change; any lawful fresh access uses Q13–Q16 and exact current scope independently. The edit does not restart Q05–Q20 periods, review targets or provider material windows.
5. **Coherent commit and recoverable retry.** Bind a deliberate immutable operation to the reviewed target/source basis and atomically record the successor/history/result. Compare current relevant authority and source state at commit. Two competing edits, receipt admission, removal, acceptance, actual fulfillment or cancellation must have a truthful source order. A matching committed operation is recovered under current result-disclosure rules, never reapplied over a newer edit or terminal state. A timeout is not permission to guess failure and create another change.
6. **Do not discard independently valid work.** Q09 permits compatible target-only changes to resolve at first admission without a fresh upload; preserve this. Do not blanket-invalidate all tokens, proofs, item drafts, accepted evidence or unrelated reviews merely because a coordination target changed. Actual material context incompatibility still requires the existing source's qualified handling. Submitted material awaiting staff processing alone is not a reason to invent recipient work or make it overdue.
7. **Current view, honest history, no invented delivery.** Native authorized request/work views should show the current target and attributable change history, while receipt views preserve their original basis. Delayed task projections cannot become the target authority or report a failed edit as committed. No automatic email, reminder, delivery acknowledgment, Q40 change-notice trigger or new mandatory task is newly authorized by this date-only capability; independently qualified existing effects are not disabled. Staff may use a separately qualified existing communication route, with its actual purpose and limits.
8. **Small bounded persistence.** Reuse source state/history and existing shared UI/work seams with a narrow typed target successor, not a calendar platform or per-view duplicate mutable truth. Index the exact source/current-revision and semantic-operation lookups; bound authorized history reads. Test actual effective grants/RLS and privileged routes during implementation, preserving the one P12 PDP and prescribed coarse Tenant defense. This research does not prescribe a table count, universal FORCE setting, blanket policy rewrite, performance SLA or numeric quota.
