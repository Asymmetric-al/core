## Ratified decision and amendments

The source must authorize the entire unchanged Submitted Original independently
of preview and business acceptance. Bind the selected received version to its
qualified immutable copy before emission. Original means that submission's
bytes, including a correction, rather than the first historical attempt,
converted preview or summary. No silent transformation or version substitution.

Use the existing private custody, current source/PDP and governed egress
boundaries. New full, range, conditional and recovery reads reauthorize.
Inherited long-stream expiry and feasible restriction termination apply.
Correction-first rejects a stale ordinary selection; admitted streams remain
version-bound without creating historical rights. Required tiered audit and
metering must be proven, not inferred from calling a logging helper.

Prefer compatible browser-managed attachment delivery with bounded server
streaming. Use existing Core Base UI/base-maia controls and native semantics;
no routine reason form, repeated confirmation, viewer prerequisite, automatic
download or new download manager. Distinguish checks, source restrictions,
session expiry, provider failure and missing bytes with safe recovery.

The application reports only stages it can observe. A click or completed server
stream does not prove browser saving, reading or acceptance. Interrupted
downloads may leave partial local files; access revocation cannot recall saved
bytes. Preserve private response/cache behavior on success and failure paths,
exact range integrity, safe names and accessible recovery.

No other-person/staff files, prior-version archive, post-closure duration,
public sharing, bulk export, deletion, retention extension or review outcome
is granted. Existing specialized source downloads retain their own contracts.
