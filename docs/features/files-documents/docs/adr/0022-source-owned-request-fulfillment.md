## Ratified decision and amendments

For the ordinary native Private Document Request, the requesting source SHALL
record fulfillment when its complete current qualified requirements are
satisfied, without a separate routine staff Complete request action. Preserve
Q21 deliberate exact acceptance for ordinary file evidence, required technical
admissibility and every genuine remaining source obligation. Upload/scan success,
task status, client counts and all-visible-items flags cannot supply that fact.

Preserve existing authorized source requiredness and non-file/waived/not-required
outcomes. Staff and tenants use only actual source-qualified powers, capabilities,
purpose and relevant revisions; explain when a lawful change can complete the
request. This adds no waiver, arbitrary hold, reopening, auto/manual mode menu,
general workflow builder or hidden routine final approval. A meaningful final
judgment is retained as source work, not quietly removed.

The source evaluates complete authoritative facts for an eligible lifecycle.
Missing/failed/filtered/paginated queries, unknown applicability, absent
definitions, drafts and canceled/withdrawn requests cannot become fulfilled by
an empty-set calculation. Legitimate complete empty/non-file sets remain possible
where the explicit source predicate permits them; no universal file count applies.

Qualify the automatic consequence of meaningful source commands and any deferred
execution under current P12 authority. Item acceptance, reading, assignment or
recipient-grant administration does not confer arbitrary completion authority.
Trusted context derives tenant/environment, actor/executor, occurrence and
attribution. Keep the exact source/requirement/policy/evidence basis and human
acceptance distinct from automatic source causation. No fictitious human Complete
action is recorded; tasks/workflows/custody cannot become alternate writers.

Every relevant qualified source change evaluates or durably arranges reevaluation.
This includes requirement changes, permitted alternatives, corrections and
relevant restrictions. Prove both orders of concurrent final updates and
membership changes: no premature completion and no lost final transition.
Use one source aggregate boundary or equivalent qualified version/fence protocol,
preserving independent review and avoiding tenant-wide locks. Source facts and
required outbox intent sharing a database commit atomically; keep external calls
and expensive processing outside locks.

Coherently preserve fulfillment, mandatory durable history/follow-up and historical
access eligibility. Recover the same semantic business effect under current
disclosure; retries, different keys or observers cannot duplicate it or replace
the original actor/time. Changed material conflicts. Known item acceptance remains
known if fulfillment is unresolved; owned recovery completes technical follow-through
without another business approval. Known fulfillment survives projection failure;
unknown commitment is not success or evidence of no effect.

Source-certified nonblocking optional work does not delay fulfillment; actual
aggregate/safety dependencies still count. Preserve durable optional receipts and
history under their retention/disclosure rules without calling them accepted or
deleting them. A required correction admitted first fences predecessor evidence
under Q03; closure first denies new ordinary admission. File selection/transfer
is not durable receipt. Reconcile uncertain admission before claiming received
or lost. No new post-completion review permission or optional-work engine follows.

Record actual durable source fulfillment F with its exact basis. Never infer it
from browser/click/upload/scan time, a mutable task timestamp, a guessed last
acceptance, observer delay or transaction-start time before a relevant wait.
Recover an earlier F only from proved durable occurrence; actual later fulfillment
uses that later occurrence. Later remediation preserves history and current
restrictions, with no silent unaccept, predecessor revival or reopening.

Ordinary intake/correction ends under existing closure rules. Q06–Q19 remain:
historical eligibility at timely F can admit the original bounded completed view,
at most 720 elapsed hours plus applicable earlier caps/current restrictions.
Late independent source completion cannot revive expired recipient authority.
Recovery preserves the original end; it does not mint another thirty days.
Fulfillment, admission, current reading, credentials/readiness and notification
remain separate.

Use the same request context for remaining source work, awaiting-staff state,
accepted items and the actual request result. Explain the possible completion
consequence before the final meaningful action; combined action wording is
appropriate only when the exact consequence is currently qualified. A stale
screen is not a promise. Preserve notes/reading context/focus on conflicts and
show truthful persistent status/next permitted action/help. Timely recipients
are not overdue because staff is reviewing. Request completion does not mean
the enclosing application or payment is approved. Retain Q21 accessible content
inspection, mobile/AT/localized/slow-network recovery and current privacy rules.
Preserve context only while disclosure remains valid, and discard delayed
results after user/tenant/request/purpose changes. A preview/history/secondary
failure must not erase independently confirmed fulfillment or disable other
independently authorized actions; unknown required authority still fails closed.

item acceptance, generic task completion and completed access. Preserve all
eighteen prior definitions. At authorized publication reconcile native source,
P12/P9 and applicable GEN-06 bindings, design/tasks and release evidence; read
full incorporated OpenSpec sections and regenerate declared projections.
