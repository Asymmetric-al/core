## Ratified decision and amendments

Provide optional contextual paired reading of two exact, source-related file
versions for currently authorized staff, without adding generic automated
difference detection, highlighting or Changed/Unchanged claims. Preserve all
existing source-specific comparison requirements, including P23 Media and
P22/P23 editorial comparison. This limits the generic Phase 29 increment; it
is not a permanent prohibition on later deliberately qualified assistance.

The owning source supplies the permitted relationship, purpose, exact versions
and meaningful statuses. Use a valid source-derived default or deliberate
selection without a new governance form. Authorize each input and their paired
presentation under one validated tenant/actor/context; do not union roles,
assignments, purposes or source rights. Filename, timestamp, matching bytes,
retained history and permission for the current file cannot authorize the pair.

Keep opened input identities stable while lawful. Refresh source status
truth separately and explain a changed review basis; never silently substitute
the newest content. Pane focus, position, viewing or scrolling does not select
an acceptance target or prove review. Q03's predecessor fence, Q21's exact
current acceptance and Q28's evidence/provenance rules remain. Comparison is
not a mandatory step, business lock, approval, adoption, publication or restore.

Compose the existing qualified reading representations and their full D32
coverage, privacy, lineage, processing and retention rules. Preserve exact
original bytes, available text/semantics and declared omissions. Each side
retains its profile/options and truthful availability; matching displayed
content does not establish equal or unchanged originals. P18 canonical artifact
serving and Q05 participant historical-content restrictions are not widened.

On roomy screens, present readable adjacent versions with clear identity and
status. Provide a usable single-column or explicit version-switching equivalent
for narrow screens, zoom and assistive technology. Preserve each permitted
version's position, zoom and clearly scoped Find, plus the original task,
notes and return focus. Independent navigation is required; optional linked
scrolling must not imply semantic/page alignment or silently clamp away content.
Do not force dragging, two cramped panes, color-only meaning or compare/dwell
ceremony. Qualify represented content as well as controls.

Distinguish technical loading/failure, supported limited coverage, expired
rendition and denied/unknown required authority. A transient network or renderer
failure alone is not revocation; retain only context still permitted by the
qualified disclosure model. On denied or unresolved required current authority,
stop affected reads and clear affected protected representations and delayed
results. If the joint pair purpose/relationship is no longer permitted, stop
that composition. Standalone reading may continue only in its independently
valid source scope. No automatic download, external viewer, re-upload demand,
raw provider link or stale private-cache fallback follows a failure.

Keep technical generations per qualified input. A transient ordered pair of
references is sufficient; no durable Pair table, combined derivative or second
workflow is required. Retry/coalescing and original deadlines follow D32.
Closing or changing this view stops its own requests; it does not cancel,
delete or renew a shared generation used elsewhere. Expiry/recovery/Ready
promotion and deletion preserve their exact input and custody boundaries.

Preserve D32 per-file limits, declared lanes and qualification obligations.
Qualify aggregate pair scheduling, device resources, network and tenant
fairness separately: neither double the limits nor halve valid single-file
capacity by assumption. Defer a pane truthfully under pressure while keeping
permitted work usable. No guessed speed, capacity or universal pairing claim
follows from two individually qualified previews.

Reuse source/P12, custody, shared UI, API and recovery owners. Prove real-role
grants/RLS/storage/privileged paths, generation and source-change races,
mixed-version/restore behavior and actual accessible staff journeys before
activation. Preserve minimal protected access evidence separately from business
review history; ordinary diagnostics contain no private document/query content.
No new domain term, permission engine, notification, editor, OCR/AI, visual
difference, comparison export or whole-Studio prerequisite is added.

## Consequences and qualification

The ordinary flow is Compare versions, a valid default or short exact selection,
comfortable independent reading and return to the same source task. Comparison
is optional assistance; it does not prove sufficient inspection or choose a
review target. An unavailable pane does not by itself reject evidence or erase
other lawful work. Source actions and specialist rules retain their owners.

Before activation, qualify the actual source/reader/composition cohort with real
roles and effective grants/RLS/Storage/privileged paths, exact generation and
source-change/cleanup races, N/N-1 compatibility/restore, measured composed load
and actual keyboard/AT/mobile/intended-reviewer journeys. Per-file qualification
does not prove two-reader capacity; accessible controls do not prove readable
document content. Monitoring uses existing accountable owners, named thresholds
and responses; it does not substitute for prevention or release evidence.
