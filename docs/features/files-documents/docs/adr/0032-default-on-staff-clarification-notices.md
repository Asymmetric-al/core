## Consequences and qualification

Participants keep one ordinary message action and honest native receipt. They
are not shown internal mail recipients, settings or provider diagnostics, and
are not asked to resend received text to fix optional email. Independently
authorized participant-facing source contacts/history remain available.

Staff may receive a minimal cue and return to current permitted context. A
question may already be handled, or the participant may have lost access;
neither creates a universal staff-notice stop or a claim that a response is
still owed. Actual source purpose, finite utility and current staff authority

an old communication. Tenant Off keeps source work intact and limits extra mail.

staff-recipient/material and recovery qualification. Use the existing control;
add no digest, unread/presence/urgency state, per-member task, inbox, email

participant/staff/admin journeys. Documentation and existing mocks are not
qualification. Named operators and measured release budgets are required.
