## What to build

Allow at most one current same-tenant Request reference per compatible appeal. Deliberate link/unlink has attribution and temporal association history but changes no membership, owner, response, access, work or financial allocation. Both permitted views render the same current source; an old Request link cannot claim prior presentation belonged to a new appeal or let a new invitation borrow acceptance. Serialize duplicate links, replies and terms changes, rejecting stale forms after intervening lifecycle changes without losing safe input. Present mixed funding, hosting and prayer Requests with each independent response, exact presented terms and next action; expose a named Request-level board lens with equivalent explicit keyboard/menu controls. Reuse F03/F04 source commands for actual historical presentation, attributed conditional/partial responses, old-terms replies and correction; contradictory contact replies require source-qualified clarification. A board move cannot fabricate presentation, supporter response, money, booking, fulfillment or organizational agreement.
