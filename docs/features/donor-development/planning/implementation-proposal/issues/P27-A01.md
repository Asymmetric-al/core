Preserve N assignees per role and multiple roles per person, one valid primary, end-dated prior facts, current-authorized receipt recovery and new attributed correction/return. - [ ] AC27-A09-02: Given a caller may reach an existing row but may not produce every possible resulting assignment state; When direct admitted-role and service-path updates attempt forbidden Tenant, subject, recipient, role, control or scope changes; Then A permitted old-row update cannot create an unauthorized new tenant, subject, recipient, role, control state or scope; effective USING/WITH CHECK, grants and bypass paths are proved.
