## What to build

Add the separate Review current matches and Apply selected changes flow for authorized assignment managers, plus native reviewed manual group edits. Freeze permitted identities, expected source/policy versions and intended targets; make selected-page versus all-matching scope explicit. Commit independent members separately through the same source guard, retain truthful partial/conflicted/not-attempted outcomes, and cancel only uncommitted work. Resume the original operation after timeout; changed queries or targets never expand or silently substitute its intent. Per-member current authority remains mandatory.

## Context and contracts

This is not an all-or-nothing tenant transfer transaction. Existing P9 source operations are reused and each member retains a durable receipt. Proposal state never replaces actual assignment and merely dismissing review does not create manual protection.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.

## Scope and non-goals

- No live-filter bulk population, per-row mandatory dialog/task, hidden target refresh, automatic adoption of protected unknown rows, or reversal of already committed members on Cancel.
