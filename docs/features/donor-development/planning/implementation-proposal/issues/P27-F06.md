## What to build

Present only current permitted P13/P15 money and P16 fulfillment source projections on the exact linked Request, with coverage/freshness, partial fulfillment and reversals. Provide deliberate owner continuation to fixed commitment recording using its own instruction/Party/representative authority, terms and confirmation. Do not copy amounts to a writable Request result or create a gift/promise from positive response alone. Missing source capability blocks only the dependent action and gives safe recovery. Other financial owner lanes appear only when independently qualified; no recurring provider activation is introduced here.
