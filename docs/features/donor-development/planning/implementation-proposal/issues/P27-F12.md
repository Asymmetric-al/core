## What to build

Deliver a tenant-scoped appeal with purpose and eligible responsible staff, optional relevant goals and no event, rating, prayer-content, public campaign or Studio prerequisite. Compose existing record shell and truthful loading/empty/denied/updating states; deeper financial controls appear only when relevant/authorized. Saving purpose changes cannot erase saved source financial facts or submit hidden unsaved monetary values. Enforce child field/existence permissions independently on all displays, counts/sorts/exports/briefs/cache and direct writes. Preserve actual history, privacy disposal and safe migration/retained-data census from first delivery; no public or missionary access follows membership.

## Context and contracts

The existing legacy public.campaigns table mixes public fundraiser/email/counter facts; do not repurpose it as P27 appeal authority. An empty legitimate appeal is a complete demonstrable behavior; Request/working-list features attach through their later qualified source commands.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.
