## What to build

Implement one current pending round bound to exact represented ministry/Parties, requested outcome, outward wording, monetary currency/cadence/duration, conditions, dates included in presentation and qualified document versions. Internal forecasts/notes/responsibility/follow-up outside that basis do not restart review. Relevant edit supersedes pending coverage; returning old values cannot revive it. Resolve one currently qualified reviewer; stable Party identity enforces any real independence floor. Decide only on sufficiently authorized actual terms, atomically committing decision/history/result/source-work intent. Source task completion/read/archive cannot approve. Include approval/change/refusal UI, concise actionable feedback when not approved, accepted-versus-notification-failed recovery and real decision-race proof.

## Context and contracts

This slice includes source-specific review work projection, field-minimized reviewer disclosure, replay access and safe restore/mixed-source operations; no P15 financial-approval reuse by policy equivalence.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.

## Scope and non-goals

- No new generic workflow, event-sourcing, list, approval, financial or task engine.
