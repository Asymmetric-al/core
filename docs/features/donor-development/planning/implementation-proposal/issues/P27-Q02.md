## What to build

Qualify the composed deployed workload, not a toy model. Produce numeric admitted envelope and measured read/command p95/error/freshness/recovery budgets with units, durations and actual provider/hardware versions. Cover largest-tenant skew and fair processing alongside an overloaded tenant, rule overlaps and finite bulk operations. Validate the exact 141 MON27 contracts against delivered signal producers, assign their accountable roles to actual operators, and exercise each distinct required response. Compatible repeated source rows may share a signal/incident/runbook; retain every ID mapping without creating 141 duplicate alarms. Preserve the exact D6 fifteen-minute and D23/D24/D25/D26 five-minute planning triggers and all other numeric windows; do not convert them into proven SLAs.

## Context and contracts

Q12 forbids an unbounded or unspecified release envelope. Source slices own bounded execution, metrics and repair controls from their first delivery; this ticket measures them together and records operational readiness. Q13 distinguishes business history, security audit and diagnostic signals. Every security/financial invariant is prevented/tested before release; monitoring adds incident detection and response. A15 supplies exact assignment dimensions; C36-04 requires named operators and honest mandatory-gate states. No repeated historical monitor row requires a duplicate product alert.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.

## Scope and non-goals

- Build all monitoring or security controls at the end.
- Add a new telemetry vendor, warehouse, queue, scheduler or arbitrary performance target.
- Treat source repair SQL or permissive/stale cache fallback as recovery.
- Claim provider/scale qualification from unit benchmarks or default demo E2E.

### AC27-Q12-01

- **GIVEN** a release profile omits a numeric bound, source coverage or supported-version measurement.
- **WHEN** activation readiness is evaluated.
- **THEN** the affected profile fails qualification with the missing evidence named.

### AC27-Q12-02

- **GIVEN** the declared maximum tenant and an overloaded tenant run concurrently.
- **WHEN** representative reads, writes and recovery execute.
- **THEN** measured budgets hold for admitted tenants or overload is visibly bounded without lost accepted work, unauthorized fallback or starvation.

### AC27-Q13-02

- **GIVEN** a declared monitor breaches its threshold.
- **WHEN** its runbook is exercised.
- **THEN** the assigned owner receives the signal and performs the named containment/reconciliation response preserving source history.
