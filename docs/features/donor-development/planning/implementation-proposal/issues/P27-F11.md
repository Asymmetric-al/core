## What to build

Bind the exact Request presentation purpose to the qualified communication/action owner. At actual dispatch/transport admission recheck current terms, required review coverage, revocation, actor/source permission and suppression; queuing alone proves none. Serialize tightening/revocation versus action start and keep earlier admitted/in-flight truth without recall claims. Record genuine past presentation without prior review as truthful historical evidence, never backdated approval, automatic send or reopening. Show Internal review separately from Supporter response and test actual user understanding of who acts next and what approval did.
