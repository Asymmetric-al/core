## What to build

Implement the deliberate scoped Apply changes automatically mode and real durable executor. Only proved rule-managed/initial-eligible responsibility can move; manual replacement, Keep, intentional vacancy and unknown provenance remain protected. Policy/assignment/control/current authority serialize at source acceptance. NHI execution rechecks current service scope and human-owner ceiling independently of historical approval. Off fences uncommitted old-generation changes while retaining accepted assignment/history, initial routing and independent work. Reenable establishes a new generation for future qualified events, never sweeps or replays prior desired owners. Coalesce superseded relevant events without deleting history or creating cycles.

## Context and contracts

There is no current D30 Auto executor in the checked workflow registry. The existing Support inbox round-robin control is unrelated. The inherited CRM staff-role shortcut and generic service role cannot authorize this effect. A same-person Keep is a real control revision and must beat later stale Auto.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.

## Scope and non-goals

- No source-to-source recursive assignment rules, rule fallthrough on uncertainty/ineligible selected target, old-policy rebound, hidden current-match catch-up, author impersonation, ratings/location/AI input or access grant.
