## What to build

Provide explicit Withdraw, Reassign, Reconsider unchanged terms and authorized prospective correction/revocation. End only exact source occurrences; preserve actor/time/outcome and continuing recipient engagement. Reassignment rechecks destination eligibility and expected head. Race authority loss/reassignment/decision in both orders and return current permitted results without replacing later state. Preserve valid historical decisions after reviewer departure; current presentation still requires current checks. Reconcile out-of-order task events and backup restore against later revocation/disposal before reads or workers resume.

## Context and contracts

No workaround text edit is required to reconsider; task closure and notifications remain projections, no second approval inbox or historical author rewrite.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen.
