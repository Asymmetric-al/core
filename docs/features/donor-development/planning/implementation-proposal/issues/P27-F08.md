## What to build

Deliver the finite initial Review not required default and per-Request Inherit/Require/Not required setting with visible effective basis. Separate configuration/exception authority from ordinary edit. Unknown policy fails the dependent prospective action but retains preparation; a proved review-free path ignores unrelated reviewer-directory outage. Default changes preserve explicit settings/history, end obsolete mandatory work as No longer required and never send a backlog or manufacture approvals. Honor final schema/version and old-client refusal from activation.

## Context and contracts

Choose only the settled finite policy, with no threshold DSL, timers, automatic expiry or universal review ceremony. Required reviewer recovery stays source-owned. Consumer activation must await the action-start fence.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.
