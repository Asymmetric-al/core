## What to build

Distinct source command for deliberate same-list clearing; show current assessment and proposed No current stage — Not yet assessed before ordinary Save. Distinguish a real tenant stage with that name. Omission/generic null upsert/failed read/age/retirement/automation/unmatched callback cannot clear. Existing absence is no-op only after current authority/revision checks. Atomically commit current absence, attributable history and durable receipt. Retry older clearing never erases later assessment; list switch/clear/assessment/lifecycle/revocation races cannot retarget saved intent. Keep same partnership/list identity, withdrawn binding, earlier assessments, pause and review obligations, finance/consent/task facts; no mandatory note, extra confirmation or task. Absence-aware counts/filters/boards/offered exports retain population; any offered board clear uses deliberate consequence and source command. Close/reopen preserves absence rather than historical last-non-null fallback.

## Context and contracts

Staff may explicitly save no current stage on the same list, including while paused, with prior assessments retained and a clear Set stage next action.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.

## Scope and non-goals

- No closed-work stage editing, bulk clearing, historical rewrite, erased assessment or implicit clear through another feature.

### AC27-P28-01

**Given** an authorized partnership has a current stage, **when** staff deliberately choose no current stage and save, **then** the current and proposed meanings are clear before Save; the same partnership/list now shows Not yet assessed and an available Set stage action, with earlier assessment retained.

### AC27-P28-02

**Given** a tenant stage is named Not yet assessed or equivalent, **when** staff inspect or choose absence, **then** the configured stage and actual no-current-assessment option remain distinguishable by meaning and stable identity.

### AC27-P28-03

**Given** a request omits stage or the current value is denied, unloaded or unavailable, **when** another edit is saved or a callback arrives, **then** the source current stage is not cleared and the UI never substitutes unknown coverage for accepted absence.

### AC27-P28-05

**Given** a successful clear has been followed by a newer assessment, **when** the old command is retried after response loss, **then** the original receipt may be returned under current authority but the newer assessment remains.

### AC27-P28-06

**Given** the source already has current absence, **when** the same-value command is submitted, **then** current authority/version checks still apply and no new assessment, transition timestamp, activity or duplicated history is created.

### AC27-P28-07

**Given** the same binding belongs to a withdrawn retained list, **when** staff deliberately clear its assessment, **then** the binding stays usable under retained-work rules and no forced list migration or loss of past assessments occurs.

### AC27-P28-08

**Given** the cleared work is closed then genuinely reopened, **when** the recorded state is reconstructed, **then** current absence remains; history is neither erased nor used as a last-non-null fallback.

### AC27-P28-09

**Given** current-stage filters, boards, counts and exports include the cleared work, **when** authorized results are recomputed, **then** the work remains represented in the no-current-stage meaning without fake stage entry, last contact, gift or financial outcome.

### AC27-P28-10

**Given** staff use keyboard, screen reader, touch or a weak connection to clear, **when** save succeeds, fails or returns an uncertain outcome, **then** input, current/proposed meaning, error/status and safe recovery remain understandable without required essay, second acknowledgment or invented follow-up.

### AC27-P29-02

**Given** paused work has an assessment or uses a withdrawn retained list, **when** authorized staff clear the assessment or continue using an eligible retained stage, **then** the deliberate change succeeds under its source rules without mandatory list migration, resuming or completing the review.
