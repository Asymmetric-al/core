## What to build

Add a currently eligible canonical Party once per appeal, retaining source identity/provenance and authorized no-op for already-in-list. Organization inclusion never expands contacts. Separate current membership from current contact/planning eligibility, Asked/response/source outcomes and ordinary saved filters. Current lookup failure cannot become empty/zero; later restriction narrows use without erasing lawful history. Include exact same-tenant old/new-row and direct-RLS/import/service proof, protected count/export/result/cache behavior, safe historical mapping and incompatible writer refusal.

## Context and contracts

No task, request, cultivation journey, approval, gift or message starts from adding a member. A permanent source revision/fence is created now for later exact outbound adapters; no membership-dependent sender activates before P27-F16.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.
