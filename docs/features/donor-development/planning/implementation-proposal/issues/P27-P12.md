## What to build

Implement deliberate source reopen with same enrollment identity and original start plus preserved close/return cycles. Revalidate current source eligibility/restrictions/responsibility and current next work. Preserve current stage/list binding or authoritative absence, including retired-stage provenance and unknown dates; no last-nonnull fallback. Refuse stale reopen over newer stage/cycle and distinguish genuinely different future work or owner-qualified mistaken-close correction. Never reopen automatically from gift/referral/message/import/timer.

## Context and contracts

Staff return to the same continuing work and retained stage or absence with clear historical provenance and fresh eligibility. P27-P01 already delivers the exact persisted list binding and nullable current assessment; richer chooser P15 is not an implementation prerequisite. Later clear/retire branches are composed with their actual source commands when they land.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.

## Scope and non-goals

- No new CRM identity, authorization engine, task/notification platform or shadow finance ledger.
- No duplicate implementation of already owned request, encounter, Party merge or finance command.

## Acceptance criteria

- [ ] Genuine same-scope return records one new cycle on same enrollment with original start and closed periods intact.
- [ ] Explicitly absent stage remains absent; existing/retired recorded stage remains historical with actual provenance, no new assessment time.
- [ ] Current authority/owner/restrictions are checked; old grants/tasks/notifications/responses/redacted bodies never revive.
- [ ] Concurrent newer stage or close defeats stale reopen/retry without overwriting state.
- [ ] Different source/purpose/scope and mistaken-close repair follows qualified disposition, not silent history union.

### AC27-P11-07

**Given** close response is lost and a retry occurs after a later transition or revoked access, **when** the original intent is recovered, **then** one accepted effect retains original actor/time; current authority governs result disclosure and the stale intent cannot close or reopen newer work.

### AC27-P12-01

**Given** closed ordinary work returns for the same Party/ministry/purpose/scope, **when** authorized staff deliberately reopen, **then** the same enrollment preserves original start and closure history and records the new return cycle.

### AC27-P12-07

**Given** a proposed return actually changes purpose, ministry or scope, or attempts mistaken-close undo/collision repair, **when** staff choose an action, **then** ordinary reopen does not silently retarget or erase history; the qualified correction/disposition path is required.
