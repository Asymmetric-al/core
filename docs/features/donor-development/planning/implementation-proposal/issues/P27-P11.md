## What to build

Add Close and actual Review→End through exact source readiness and creating-writer fence. Obtain bounded complete affected-obligation evidence beyond visible page and protect readiness metadata separately from blocker body/history. Unknown/incomplete is not empty. Required work must be fulfilled or receive qualified disposition; independent legitimate obligations retain authority/responsibility/discoverability. Source acceptance/history/receipt/local intent atomic at trusted time. Actual review end is Completed; direct close future review is No longer required. Closed row leaves current work, remains permissioned history; no change to stage/Party lifecycle/assignment/finance/consent.

## Context and contracts

Staff deliberately close the exact work while independently valid commitments and obligations remain accountable and history remains truthful.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. ## Acceptance criteria

- [ ] No gift/response/date/score or filtered empty view alone closes; prayer/practical followthrough remains meaningful.
- [ ] Outside-first-page and protected obligations affect only authorized minimal readiness; unknown owner response cannot pass.
- [ ] Concurrent blocking-work create versus close exercises both orderings with no accepted stranded combination.
- [ ] Independent obligations survive with current owner/route; reassigning unfinished same development work does not count as completion.
- [ ] DirectClose future review means No longer required, realReviewEnd means Completed; old attention cannot newly release.
- [ ] Lost response/revoked replay/lawful body deletion preserves one attributed close and no current-view/financial/contact false increments.
- [ ] With actual paused and closed partnerships, authorized late Request response or source gift records preserve pause/review/closure and ended effects; genuine return uses explicit reopen and a late gift never reopens work. This is the primary real composed AC27-F08-01 proof; F05 owns Request behavior and keeps the AC shared.

### AC27-P08-05

**Given** a review action resumes or closes work, **when** the qualified source command commits, **then** affected obligations are explicitly accounted for; unrelated tasks, gifts, commitments, consent and public content remain unchanged.

### AC27-P11-01

**Given** staff inspect cases of declined ask, ongoing promised prayer follow-through, continuing giving without further development work and a deliberate temporary pause, **when** they choose a source action, **then** the UI distinguishes these meanings and prevents treating missing date or visible emptiness alone as completed work.

### AC27-P11-02

**Given** a relevant promise exists outside the first page or is protected from the actor, **when** closure readiness is evaluated, **then** complete owner evidence determines readiness; permitted minimal outcomes disclose only authorized information and unknown checks cannot pass as empty.

### AC27-P11-03

**Given** an independent obligation has valid continuing authority and responsibility, **when** closure disposes the development-specific work, **then** the independent obligation stays findable and actionable; reassigning the same continuing development work does not falsely satisfy readiness.

### AC27-P11-04

**Given** close races new work, review changes or authority revocation through any admitted writer, **when** real transactions exercise both orders, **then** no accepted combination strands required work or permits stale authority; closure and the incompatible new work cannot both pass separate stale prechecks.

### AC27-P11-06

**Given** staff close one of several scoped relationships, **when** current views, counts and financial/contact sources are reconciled, **then** only that enrollment leaves current-work scope; the preserved stage, requests, assignments, gifts, consent and other enrollments are unchanged and no last-contact/successful-ask increment occurs.

### AC27-P11-08

**Given** closed work is viewed under current permissions after redaction or lawful content deletion, **when** history and derived reports are opened, **then** the admitted structural history remains attributable without restoring forbidden content, changing closed-period interpretation or fabricating successful outcomes.
