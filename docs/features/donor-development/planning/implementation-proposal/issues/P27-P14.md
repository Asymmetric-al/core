## What to build

Create stable organization/list/stage identities and usable starting lists without a forced rationale/default/assignment wizard. Enforce readable names and one documented authoritative canonical naming comparison within qualified scope; do not invent arbitrary ASCII/fuzzy restrictions. Supply the narrow list discovery/use contract needed by P27-P01: at least one complete usable approved starter list, exact stable list/stage references, current availability/eligibility and independently authorized read projection. Ordinary admission can explicitly consume that list with optional stage before the richer P27-P15 chooser exists. This slice has no enrollment dependency. Commit the complete initial definitions, configuration history, trusted attribution and durable receipt atomically; no selectable shell. Same intent creates once; changed payload conflicts; replay after later edits returns historical result without overwriting current configuration. Keep creation authority separate from journey use/history/aggregate authority. Prove non-owner DML/RPC boundaries, revoked actor recovery, hidden-name indistinguishability, independent tenant concurrency and escaped label/export handling. Preserve organization ownership on creator departure, inherited work and financial/consent/task facts. Evidence-only migration maps proven identity and uncertainty; no automatic donor work. Optional copying is not required; explicitly keep it absent unless separately qualified. If offered, AC27-P16-04 limits it to independent permitted configuration identities.

## Context and contracts

An authorized configurator can use supplied starting definitions or deliberately create a complete additional list, cancel safely and recover the accepted list after a lost response.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.
