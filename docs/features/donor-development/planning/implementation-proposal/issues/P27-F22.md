## What to build

Attach the exact P15 intake lineage to authorized staging/batch row and carry-forward identities. Continue existing entry/validation/sole commit; known valid staging creates no duplicate precursor. Only exact owner-confirmed covered posting resolves awaiting-recording; generic status/similar amount or withheld/partial coverage cannot. Preserve per-item partial results, current-authorized completion projection and source history. Commit/source-lineage local changes stay atomic; independently already posted money survives failed consumer projection and is reconciled without reposting/receipt/P16 application. Race material report correction against exact resolution and distinguish incidental metadata edits. Safe retry returns one accepted operation without overwriting later evidence.
