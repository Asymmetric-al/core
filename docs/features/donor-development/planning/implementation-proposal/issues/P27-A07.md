## What to build

Add Use rules again as one current-source command on an exact protected responsibility. Show the current eligible outcome and mode before Save. In Review, release protection and expose the exact current proposal while the actual person remains; in Auto, release and apply only the displayed currently eligible result through the qualified source boundary. With no match/unknown/ineligible target, preserve valid responsibility and show why there is no transfer. A changed rule, target, context or source revision conflicts rather than silently substituting an effect. Record the release and resulting source outcome atomically or neither.
