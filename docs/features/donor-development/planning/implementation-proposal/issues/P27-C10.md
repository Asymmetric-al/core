## What to build

Build native views over existing source facts with explicit grain and denominators. Keep Request forecasts, source-confirmed outcomes, separate financial lenses/entity/currency/period/coverage, exchange recency, outreach and next-action health independent. Do not count loaded pages as population or sum overlapping staff/appeal attribution as conserved money. Expose reproducible source tuple/cutoff and currently authorized reconstructible projections; choose caching/materialization only from measured costs. Any campaign-temporal profile affected by E7 is visibly unavailable until its owner adapter is qualified while direct-giving and nonfinancial work still load.
