## What to build

Extend the actual qualified P6/P32 producer-purpose admission path with exact continuing membership/no-exclusion and appeal-origin fences. A member change atomically advances the authoritative fence; no outbox-only safety update. Frozen send populations narrow without replacements. Different appeal/contact/purpose relabelling cannot bypass the original applicable restriction. Preserve independent receipts, service responses and fulfillment; appeal link alone is not dependence. Report dispatching/submitted/unknown outcomes truthfully and reconcile rather than recall or duplicate send. Return never resumes the ended solicitation occurrence; restore must reconcile later restrictions before source readers/workers resume.

## Context and contracts

The demo deliberately stalls all secondary projection workers while ordering exclusion versus actual dispatch in both directions. A native/Studio duplicate delivery converges on the same source effect; generalized email timing or automatic reminder rules are out of scope.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.
