## What to build

One coherent current binding; same Party/ministry/purpose/source scope and independent tasks/asks/finance/consent remain. No name/rank/historical-stage mapping, restored old assessment or new ordinary enrollment. Destination is valid for new attachment at actual acceptance; current withdrawn source may remain. Returning to earlier A requires current A eligibility. Malformed/omitted/unresolved stage intent is not intentional absence; same-list/unsaved B-then-A cannot clear. Atomic source/history/result/effect-intent with expected revision; stage-versus-switch, opposing switches, ABA, retirement/withdrawal/revocation/lifecycle races, lost responses and old accepted receipts never mismatch scope or overwrite newer work. Minimum understandable before/after facts require independent permission without exposing full private history. Real nonowner/grants/RLS/functions/service/import/repair doors enforce scope, immutable history, current disclosure and correct resulting-row checks. Full contextual current/proposed/accepted stage-or-absence UI with one save/cancel, safe late responses, protected input and usable route/focus after a row exits its filter. Paused edit actions preserve current permitted review details; closed-work editing remains unavailable. Current/list/stage filters, history, optional reports/exports and duration definitions retain all assessed/unassessed/retired/withdrawn work and unknown intervals. Configuration is not movement; returns and gaps are not linear progress or donor worth. Complete the catalog cohort readiness proof: create/customize/retire/withdraw/restore/choose/default/switch/clear and pause/return integration, retained-data/mixed-version/restore fences, exact monitor handoffs and representative critical user tasks. ## Context and contracts

Staff deliberately switch a partnership to another currently eligible approved list, choose a valid target stage or explicit absence, and preserve identity, history and paused context through reliable recovery.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.

## Scope and non-goals

- No bulk/cross-scope transfer, historical correction engine, stage mapping rules, per-list assessment restore store, automatic migration or provider dependence.
- No finance approval/receipt/commitment source behavior and no missionary performance monitoring.
