## What to build

Stable identity is independent of display name/order/translation; changed meaning gets a new identity. No ordinary deletion or rewriting accepted history. Template changes require deliberate qualified adoption; platform security changes remain mandatory. Retirement prevents fresh stage choice but preserves unchanged retired values, source dates and continued task/owner edits and same-work return. Restore preserves identity and adds only config history. Every list usable for new or retained work has at least one selectable stage, even withdrawn/no-visible-use lists. Two last-stage retirements cannot both commit; valid explicit replacement is atomic. Do not infer a stage default from order. Validate complete reorder manifests rather than treating a filtered view as catalog; bounded concurrent config edits, stale revisions, receipts, projection reconciliation and safe name rendering remain inside this command. Readable configuration editor has keyboard/single-pointer alternatives to drag; current/retired stage views and offered board columns preserve all authorized work and historical meanings.

## Context and contracts

An authorized organization configurator can add stages, change same-meaning wording/guidance, reorder, retire or restore them while retaining stable references and explainable history.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.

## Scope and non-goals

- No new stage-default feature is required; honor an independently qualified existing dependency if present.
- No implicit remapping, synthetic stage movement, bulk reassessment, mass journey rewrite or auto template update.
