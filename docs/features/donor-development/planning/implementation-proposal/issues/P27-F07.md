## What to build

Provide scoped Request counts and versioned forecast views by legal entity/currency/horizon alongside appeal nonfinancial measures. Include monetary-unknown and nonfinancial Requests in ordinary counts, exclude nonapplicable amounts from money, and deduplicate exact Requests across alternative proposals, attribution joins and multi-appeal references. Label grain/scope/period/current-or-historical coverage. Use compatible invitation population for response rate, preserve historical denominators and goal versions, and show no percentage for absent/zero/denied/incomplete denominator. Over-target actuals remain visible. Financial received-toward-appeal remains the separate qualified source-measure slice.
