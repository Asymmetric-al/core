## What to build

Capture coherent finite intended Party identities once on explicit all-results selection; preserve them through filter/page/sort/virtualization changes. Review and Clear selection include off-page members. Check measured group ceiling before admission and offer smaller selection without silent truncation. Each item rechecks current permissions/eligibility and atomically commits accepted disposition/history/receipt/actual producer fence. Partial outcomes name added/already-present/skipped/conflicted/unavailable/cancelled/unresolved within disclosure limits. Cancel only unaccepted work; check/retry same operation never reruns filter or reapplies old Add over later removal. Ship measured group capture/recovery and low-bandwidth UI proof.

## Context and contracts

Use existing bounded-operation execution conventions with a P27-owned finite selection contract, not a new list/subscription engine. Current source safety can narrow accepted population but cannot substitute new people.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.
