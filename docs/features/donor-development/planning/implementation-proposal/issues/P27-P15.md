## What to build

Offer the same currently eligible approved lists for the same source/context across surfaces; no invented Party-type/ministry/team/app gate. Preserve existing valid intent without a repeated chooser. New-work omission means no assessment; required list/source identity, lead and accountability remain. Absent stage is source null, not a fake catalog entry or writable assessedness flag. Changing an unsent list visibly resolves its incompatible stage without mapping equal labels/ranks, clears no saved work and preserves unrelated input. Server validates concrete final list/stage-or-absence; missing list never means use latest default. Keep no-current-assessment, known/retired value, hidden field, loading, failed/partial/legacy-unknown distinct through source reads, UI, pagination and export. Basic current population retains unassessed work. Same ordinary work with another/withdrawn retained list is reused without rebinding or clearing. Finite reviewed-group members retain original intent and per-member outcomes through concurrency, withdrawal and lost responses.

## Context and contracts

Staff select the appropriate eligible list and optionally a current stage in one deliberate Start, while unassessed work remains visible and existing ordinary work is reused unchanged.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.

## Scope and non-goals

- No default-selection heuristics (P27-P18), later stage change (P27-P16), saved list transfer (P27-P21) or implicit same-list clear (P27-P20).
- Do not build a second admission command or finite-group executor; consume the parent contracts and verify the stage-specific composition.
