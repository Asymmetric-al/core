## What to build

Provide explicit Remove from working list, Exclude from this appeal and Return to list actions. Exclusion can be recorded for an eligible-to-record candidate never included; it is not global consent or donor refusal. Plain Add/import/retry skips Removed/Excluded. Return shows previous disposition and rechecks head/eligibility, restoring planning only. Keep churches and human contact identity distinct so changing the representative cannot bypass the same organization restriction. Record actual late facts without re-inclusion. Current-source fence advancement and required history/receipt are atomic, with conflict/recovery and accessible focus when a row leaves the filter.

## Context and contracts

No Return revives ended tasks/reviews/messages; no Remove recalls admitted communication or erases history. Critical pilot misunderstanding of planned-versus-asked or remove-versus-recall blocks expansion.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.
