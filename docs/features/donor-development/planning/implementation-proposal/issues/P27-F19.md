## What to build

Close atomically fences new appeal planning/solicitation and records lawful disposition or qualified durable handoff of every affected appeal-owned obligation. Independent hosting/finance/service work continues with eligible actor/next action or owned exception; missing required authority/disposition preserves source state with repair. Cancellation is an honest closing disposition and archive is view/retention only. Late answers/gifts stay recordable without reopening; deliberate Reopen retains closure and admits fresh work, never ended occurrence revival. No last-member/goal autoclose or prayer recurring check-in. Deliver the complete accessible create/link/respond/close/recover journey and safe kill/rollback after mixed writes.

## Context and contracts

Closure consumes each affected source contract; it does not require all independent finance/hosting fulfillment to finish. Native and optional workflow consumers must converge on one legitimate effect per source purpose. C-01 corrections remain source-gated and cannot be executed by close.

Current authority, tenant/field/history-safe read and write behavior, atomic source history/receipt/required intent, truthful lost-response recovery and applicable two-session concurrency proof accompany this slice. Base UI/base-maia/Zinc, keyboard/screen-reader/mobile/zoom behavior and slow/failing network recovery accompany every reached screen. These are in-slice delivery obligations under REQ27-Q01–Q14, not deferred to final qualification. Terminal Q tickets prove composition and release evidence.

## Scope and non-goals

- No new generic workflow, event-sourcing, list, approval, financial or task engine.
