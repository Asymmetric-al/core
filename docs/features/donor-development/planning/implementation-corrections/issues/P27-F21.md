## What to build

Implement the ratified narrow P15 intake-purpose source envelope and safe P27 projection: trusted tenant/recorder/time, attributed actual receipt/handling assertion and occurrence precision, stable intake identity, permitted context and eligible next actor or owned exception. Reporter, reported holder and responsible actor are independent; unknown holder/donor/amount/intended entity/allocation remain explicit without fake Party, default currency/entity or nullable financial-root escape. Reuse valid staging where scope fits, but incomplete intake may precede a valid financial batch and valid staging needs no mandatory precursor record. No photograph, signature, second routine approval, bank field, upload, contribution, receipt or pledge is created. Provide report-only safe detail and current next action, qualified source recovery owner and actual small-screen/accessibility proof; no full batch grid on phones.
