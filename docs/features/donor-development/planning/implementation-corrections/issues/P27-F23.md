## What to build

Keep same-intent idempotency distinct from independent human reports. Authorized source resolution identifies the same actual item, preserves both origins and selects one canonical lineage without fuzzy matching by amount/name/date/check number. One item shown through multiple appeals/designation lines remains one intake/work/source gift; distinct checks stay distinct. Reconcile a known existing source-recorded gift via exact allowed lineage with no new posting/receipt/fulfillment. Correct a mistaken correspondence through attributed source history and current authority, never editing immutable money. Unknown or contradictory coverage retains an owned exception.
