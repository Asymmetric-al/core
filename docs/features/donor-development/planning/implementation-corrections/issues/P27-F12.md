## What to build

Deliver a tenant-scoped appeal with purpose and eligible responsible staff, optional relevant goals and no event, rating, prayer-content, public campaign or Studio prerequisite. Compose existing record shell and truthful loading/empty/denied/updating states; deeper financial controls appear only when relevant/authorized. Saving purpose changes cannot erase saved source financial facts or submit hidden unsaved monetary values. Enforce child field/existence permissions independently on all displays, counts/sorts/exports/briefs/cache and direct writes. Preserve actual history, privacy disposal and safe migration/retained-data census from first delivery; no public or missionary access follows membership.
