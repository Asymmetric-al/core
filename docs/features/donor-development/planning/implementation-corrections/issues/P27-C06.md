## What to build

Add the finite selected-band/known-empty OR policy for one exact qualified financial basis, gated separately from ratings. After a fresh baseline, a compatible observed false→true transition starts one durable source episode with combined current reasons. Unknown is neither false nor an entry; imports/corrections/policy changes never manufacture a new adverse occurrence. Project the currently actionable source into existing Tasks using exact recipient/action/closure and permanent semantic effect identity. Provide No change needed and deliberate independently authorized follow-up; claim/comment/read are neither completion nor independent work. Ratings Off or review Off immediately withdraws every solely automatic unresolved episode, including claimed/commented work, as No longer required while preserving independent obligations and completed evidence. Handle denied recipients, outage and projection failure without guessing people or claiming completed business work.
