   - the shared **`DataGrid`** exists but has no consumer (§2.1).

### 2.2 Gaps a Data Tools build must add to `packages/ui`, never as app-local copies

1. Stepper.
2. Generic file input and drop zone, plus resumable large-file transfer. Transfer is a Phase 29 / Phase 30 engineering seam, not only UI.
3. An editable grid with per-cell validation, `aria-invalid`, and a linked error summary. Share it with Phase 15.
4. A live-region announcer.
5. A Switch checklist / timeline composition.
6. A spreadsheet (XLSX) reader and writer library. Q11 cl. 5 allows open-source parsing libraries (DL:551).

### 2.4 Most specific owner precedents for an import journey
